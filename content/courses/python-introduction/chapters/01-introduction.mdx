# Introduction to Python

Python is a high-level, interpreted programming language known for its simplicity and readability. It was created by Guido van Rossum and first released in 1991.

## Why Python?

Python has become one of the most popular programming languages in the world due to several key characteristics:

- **Readable syntax** — Python code reads almost like English
- **Versatile** — Used in web development, data science, AI, automation, and more
- **Large ecosystem** — Thousands of libraries and frameworks available
- **Beginner-friendly** — Great for learning programming concepts

## Python use cases

Python is used in many different fields:

| Field | Examples |
|-------|----------|
| Web Development | Django, Flask, FastAPI |
| Data Science | Pandas, NumPy, Matplotlib |
| Machine Learning | TensorFlow, PyTorch, scikit-learn |
| Automation | Scripting, testing, DevOps |
| Game Development | Pygame, Panda3D |

## Python versions

Today, there are two main Python versions in use:

- **Python 2** — Legacy version, no longer supported (2020)
- **Python 3** — Current version, actively maintained

This course focuses on **Python 3**.

## Your first Python script

Let's write a simple "Hello, World!" program:

```python
print("Hello, World!")
```

When you run this code, it will output:

```
Hello, World!
```

That's it! You've just written your first Python program. In the next part, we'll set up your development environment.
