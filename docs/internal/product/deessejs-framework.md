# DeesseJS — The Framework

> **Status:** Active Development
> **Last Updated:** 2026-06-09

---

## What is DeesseJS?

**DeesseJS is the Laravel for TypeScript.**

A modular, plugin-based TypeScript framework that provides essential packages for modern development. It's not an agent framework — it's a collection of tools that make TypeScript development faster, more standardized, and more maintainable.

---

## Philosophy

### Laravel Parallel

| Laravel (PHP) | DeesseJS (TypeScript) |
|---------------|----------------------|
| Eloquent ORM | Collections (CMS-like) |
| Fortify/Sanctum | RPC + Auth |
| Blade templates | Admin Dashboard |
| Artisan CLI | DeesseJS CLI |
| Composer packages | NPM packages |

### Core Principles

1. **Modular** — Use only what you need
2. **OSS** — Free, forever
3. **Own your code** — No lock-in, copy-paste when needed
4. **Standardized** — Patterns that scale across projects
5. **TypeScript-first** — Full type safety
