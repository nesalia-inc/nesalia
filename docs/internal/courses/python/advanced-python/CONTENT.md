# Advanced Python - Course Content

## Course Overview

Advanced Python programming covering sophisticated concepts for building production-ready software engineering applications.

## Chapters

### Chapter 1: Advanced Functions
- **Part 1:** Decorators and decorator patterns
- **Part 2:** functools module (wraps, lru_cache, partial)
- **Part 3:** Generators and generator expressions
- **Part 4:** Context managers and the with statement
- **Part 5:** Walrus operator (`:=`)

### Chapter 2: Advanced Data Structures
- **Part 1:** Collections module (Counter, deque, defaultdict, OrderedDict)
- **Part 2:** ChainMap and namedtuple
- **Part 3:** List, set, and dictionary comprehensions
- **Part 4:** Sorting with custom keys (sorted, sort)

### Chapter 3: Object-Oriented Programming Deep Dive
- **Part 1:** Multiple inheritance and MRO (Method Resolution Order)
- **Part 2:** Super() and cooperative multiple inheritance
- **Part 3:** Abstract classes and interfaces
- **Part 4:** Enumerations (enum module, Enum, IntEnum, Flag)
- **Part 5:** Properties and the @property decorator
- **Part 6:** Dunder methods (__str__, __repr__, __eq__, __hash__, __len__, __iter__)
- **Part 7:** Data classes (@dataclass)
- **Part 8:** Descriptors and the descriptor protocol
- **Part 9:** Structural pattern matching (match/case)

### Chapter 4: Metaprogramming
- **Part 1:** Understanding __init__, __new__, __call__
- **Part 2:** __slots__ for memory optimization
- **Part 3:** Custom metaclasses
- **Part 4:** Class creation patterns

### Chapter 5: Advanced Type Annotations
- **Part 1:** Generic types (List[T], Dict[K, V])
- **Part 2:** Union, Optional, and Literal types
- **Part 3:** Type aliases and NewType
- **Part 4:** TypedDict for structured dictionaries
- **Part 5:** Protocols and structural typing
- **Part 6:** TypeVar and bounded generics
- **Part 7:** Self types and conditional types
- **Part 8:** @overload for function overloading
- **Part 9:** @override for method overriding
- **Part 10:** @final to prevent overriding

### Chapter 6: Collections and Iterators
- **Part 1:** collections.abc module (Callable, Iterable, Iterator, Container, Sequence)
- **Part 2:** Implementing custom iterables
- **Part 3:** ABCs for interfaces (Sized, Hashable, Collection)

### Chapter 7: Concurrency and Parallelism
- **Part 1:** Threading and the GIL
- **Part 2:** Multiprocessing for CPU-bound tasks
- **Part 3:** AsyncIO fundamentals
- **Part 4:** await, async def, and Task
- **Part 5:** Concurrent.futures (ThreadPoolExecutor, ProcessPoolExecutor)
- **Part 6:** Exception groups and TaskGroup (Python 3.11+)

### Chapter 8: Testing and Debugging
- **Part 1:** Unit testing with unittest and pytest
- **Part 2:** Fixtures and mocking
- **Part 3:** Coverage analysis
- **Part 4:** Debugging techniques and pdb

### Chapter 9: Design Patterns
- **Part 1:** Singleton and Factory patterns
- **Part 2:** Observer pattern
- **Part 3:** Strategy and State patterns
- **Part 4:** Builder and Prototype patterns

### Chapter 10: Working with External Data
- **Part 1:** JSON and Pickle serialization
- **Part 2:** YAML parsing
- **Part 3:** Regular expressions (re module)
- **Part 4:** CSV and Pandas basics

### Chapter 11: Production Python
- **Part 1:** Logging configuration
- **Part 2:** Environment variables and config management
- **Part 3:** Virtual environments and dependency management
- **Part 4:** Type checking with mypy
- **Part 5:** Code formatting with Black and Ruff
