# What is Python?

Python is a programming language that lets you write instructions for your computer. When you learn Python, you can tell the computer to solve problems, automate tasks, and build applications.

## Why We Use Python

Python exists because we needed a language that humans could read easily. Unlike languages designed for computers to process quickly, Python prioritizes being understandable by people.

When you write Python code, it looks similar to plain English. This makes it easier to learn programming concepts without fighting complicated syntax.

## What We Build with Python

Python handles many different tasks:

**Web applications** — Websites and online services run on Python. Companies use it to process data, handle user requests, and manage databases.

**Automation scripts** — Python can perform repetitive tasks automatically. You can write a script to rename hundreds of files, extract information from documents, or send scheduled emails.

**Data analysis** — Python processes and analyzes data. Scientists, analysts, and researchers use it to find patterns and make decisions from large datasets.

**Simple programs** — Python builds tools, games, and utilities. You can create anything from a calculator to a small game.

## Python Feels Natural

Python reads like instructions rather than code. Compare how we tell a computer to display a message:

```python
print("Hello, World!")
```

The word `print` means "display on screen." The quotes around "Hello, World!" mark the text we want to show. You do not need special symbols or complex structure.

## Your First Line of Code

You already saw a Python instruction above. The `print` function displays text. We use quotes to mark text as a string, which means a sequence of characters.

```python
print("Hello, World!")
```

This outputs:

```
Hello, World!
```

You run this instruction, and the computer responds by showing the text.
