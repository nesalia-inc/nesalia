# What is Python?

Python is a high-level, interpreted programming language that prioritizes code readability and simplicity. Guido van Rossum created Python and released it in 1991, designing it around a philosophy that makes programming accessible and enjoyable.

## The Zen of Python

Python's design philosophy appears in 19 guiding principles called "The Zen of Python." We access these principles by running `import this` in any Python interpreter:

```python
import this
```

This outputs principles including:
- Beautiful is better than ugly
- Explicit is better than implicit
- Simple is better than complex
- Readability counts

## Primary Use Cases

### Web Development

We build robust web applications using frameworks like Django, Flask, and FastAPI:

```python
from flask import Flask

app = Flask(__name__)

@app.route("/")
def hello():
    return "Hello, World!"

app.run(debug=True)
```

### Data Science and Machine Learning

Python dominates data analysis through libraries like pandas, NumPy, and scikit-learn:

```python
import pandas as pd

data = pd.DataFrame({
    "product": ["Widget A", "Widget B", "Widget C"],
    "sales": [150, 230, 89],
    "price": [29.99, 49.99, 19.99]
})

total_revenue = (data["sales"] * data["price"]).sum()
print(f"Total revenue: ${total_revenue:.2f}")
```

### Automation and Scripting

We use Python to automate repetitive tasks efficiently:

```python
import shutil
import os
from datetime import datetime

def backup_file(source_path, destination_folder):
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    backup_name = f"backup_{timestamp}"
    shutil.copy2(source_path, f"{destination_folder}/{backup_name}")
    print(f"Backed up {source_path} to {destination_folder}")
```

### Software Testing

We write automated tests using frameworks like pytest:

```python
import pytest

def add_numbers(a, b):
    return a + b

def test_add_positive_numbers():
    assert add_numbers(2, 3) == 5

def test_add_negative_numbers():
    assert add_numbers(-1, -1) == -2

def test_add_mixed_numbers():
    assert add_numbers(5, -3) == 2
```

### Game Development

We create games using libraries like Pygame:

```python
import pygame

pygame.init()
screen = pygame.display.set_mode((400, 300))
pygame.display.set_caption("My First Game")

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
    screen.fill((100, 149, 237))  # Cornflower blue
    pygame.display.flip()

pygame.quit()
```
