# Writing Your First Python Script

We write our first Python program after setting up the environment. This section covers Python syntax fundamentals through practical examples.

## What is a Script

A Python script is a file containing Python code that the computer executes. Scripts have the `.py` extension. Python interprets the instructions line by line.

## Hello, World!

The traditional first program prints "Hello, World!" to the screen.

We create `hello_world.py`:

```python
# This is my first Python program
print("Hello, World!")
```

We run it:

```bash
python hello_world.py
```

Output:

```
Hello, World!
```

This one line of code demonstrates:
- Python's `print()` function
- Writing strings (text in quotes)
- Comments (text preceded by `#`)

## Comments

Comments provide notes for humans reading code. Python ignores comments when running.

```python
# This is a single-line comment

"""
This is a multi-line comment.
It can span several lines.
Useful for longer explanations.
"""

# Calculate the area of a rectangle
length = 10  # length in meters
width = 5    # width in meters
area = length * width  # area in square meters
print(area)  # outputs: 50
```

## Variables and Data Types

Variables store information for later use. Python provides several basic data types.

### Numbers

```python
# Integers (whole numbers)
age = 25
year = 2024

# Floats (decimal numbers)
temperature = 98.6
price = 19.99

# Arithmetic operations
sum_total = age + year
product = age * 2
division = year / 4  # Result is a float: 506.0
```

### Strings

Strings hold text data:

```python
name = "Alice"
greeting = 'Hello, World!'  # Single or double quotes work
message = """This is a multi-line
string that spans
several lines."""

first_name = "John"
last_name = "Doe"
full_name = first_name + " " + last_name  # Concatenation
print(full_name)  # Output: John Doe

name_upper = name.upper()
name_lower = name.lower()
name_length = len(name)
print(f"{name_upper}, length: {name_length}")
# Output: ALICE, length: 5
```

### Booleans

Booleans represent true or false:

```python
is_python_fun = True
is_sky_green = False

result = 10 > 5    # True
result = 7 == 7    # True (double equals for comparison)
result = 3 != 5    # True (not equal)
result = 10 <= 5   # False

and_result = True and False   # False
or_result = True or False     # True
not_result = not True          # False
```

### Lists

Lists hold ordered collections of items:

```python
fruits = ["apple", "banana", "cherry"]
numbers = [1, 2, 3, 4, 5]
mixed = ["hello", 42, True, 3.14]

first_fruit = fruits[0]    # "apple" (indexing starts at 0)
second_number = numbers[1] # 2

first_two = fruits[0:2]   # ["apple", "banana"]
last_two = numbers[3:]     # [4, 5]

fruits.append("date")      # Add to end
fruits.insert(1, "apricot") # Insert at index
fruits.remove("banana")    # Remove by value
removed = fruits.pop()     # Remove and return last item

print(fruits)  # Modified list
```

## Control Flow

### Conditional Statements

```python
temperature = 72

if temperature > 80:
    print("It's hot outside!")
elif temperature > 60:
    print("It's nice weather.")
else:
    print("It's cold outside!")
```

### For Loops

For loops iterate over sequences:

```python
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(f"I like {fruit}")

for i in range(5):
    print(i)  # Prints 0, 1, 2, 3, 4

for i in range(2, 6):
    print(i)  # Prints 2, 3, 4, 5

for index, fruit in enumerate(fruits):
    print(f"{index + 1}. {fruit}")
```

### While Loops

While loops repeat while a condition is true:

```python
countdown = 5
while countdown > 0:
    print(countdown)
    countdown -= 1
print("Liftoff!")
```

### Loop Control

```python
for number in range(10):
    if number == 5:
        break
    print(number)  # Prints 0, 1, 2, 3, 4

for number in range(5):
    if number == 2:
        continue
    print(number)  # Prints 0, 1, 3, 4
```

## Functions

Functions are reusable blocks of code:

```python
def greet(name):
    """Return a greeting message for the given name."""
    return f"Hello, {name}! Nice to meet you."

message = greet("Alice")
print(message)

def calculate_area(length, width):
    """Calculate the area of a rectangle."""
    return length * width

area = calculate_area(10, 5)
print(f"The area is {area} square units.")

def power(base, exponent=2):
    return base ** exponent

print(power(3))    # 9 (3^2)
print(power(3, 3)) # 27 (3^3)
```

### Multiple Return Values

```python
def get_statistics(numbers):
    """Return multiple statistics."""
    return min(numbers), max(numbers), sum(numbers), len(numbers)

data = [10, 20, 30, 40, 50]
minimum, maximum, total, count = get_statistics(data)

print(f"Min: {minimum}, Max: {maximum}")
print(f"Total: {total}, Average: {total / count}")
```

## A Complete Program

We build a task manager that demonstrates putting concepts together:

```python
"""
Task Manager - Our First Python Project
A program to add, view, and manage tasks.
"""

def display_menu():
    """Show the available options."""
    print("\n" + "=" * 40)
    print("       TASK MANAGER")
    print("=" * 40)
    print("1. View tasks")
    print("2. Add a task")
    print("3. Remove a task")
    print("4. Exit")
    print("-" * 40)

def view_tasks(tasks):
    """Display all current tasks."""
    if not tasks:
        print("No tasks yet. Add some tasks first!")
        return

    print("\nYour Tasks:")
    for index, task in enumerate(tasks, 1):
        print(f"  {index}. {task}")

def add_task(tasks):
    """Add a new task."""
    task = input("Enter your task: ").strip()
    if task:
        tasks.append(task)
        print(f"Added: '{task}'")
    else:
        print("Task cannot be empty.")

def remove_task(tasks):
    """Remove a task by number."""
    if not tasks:
        print("No tasks to remove.")
        return

    view_tasks(tasks)
    try:
        choice = int(input("Enter task number to remove: "))
        if 1 <= choice <= len(tasks):
            removed = tasks.pop(choice - 1)
            print(f"Removed: '{removed}'")
        else:
            print("Invalid task number.")
    except ValueError:
        print("Please enter a valid number.")

def main():
    """Main program loop."""
    tasks = []
    running = True

    print("Welcome to Task Manager!")

    while running:
        display_menu()
        choice = input("Choose an option (1-4): ").strip()

        if choice == "1":
            view_tasks(tasks)
        elif choice == "2":
            add_task(tasks)
        elif choice == "3":
            remove_task(tasks)
        elif choice == "4":
            print("Goodbye!")
            running = False
        else:
            print("Invalid choice. Please try again.")

if __name__ == "__main__":
    main()
```

## Common Python Patterns

### List Comprehensions

We create lists concisely with list comprehensions:

```python
squares = []
for num in range(10):
    squares.append(num ** 2)

squares = [num ** 2 for num in range(10)]

even_squares = [num ** 2 for num in range(10) if num % 2 == 0]
# Result: [0, 4, 16, 36, 64]
```

### String Formatting

```python
name = "Alice"
age = 30
city = "New York"

message = f"{name} is {age} years old and lives in {city}."
print(message)

message = "{} is {} years old and lives in {}.".format(name, age, city)

message = "%s is %d years old and lives in %s." % (name, age, city)
```

### Error Handling

```python
try:
    number = int(input("Enter a number: "))
    result = 10 / number
    print(f"Result: {result}")
except ValueError:
    print("That's not a valid number.")
except ZeroDivisionError:
    print("Cannot divide by zero.")
finally:
    print("Operation complete.")
```

## Debugging Tips

When code does not work as expected:

```python
def buggy_function(x, y):
    result = x + y
    print(f"DEBUG: x={x}, y={y}, result={result}")
    return result
```

We start simple and add complexity gradually.
