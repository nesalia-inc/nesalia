# Setting Up Your Development Environment

We set up the development environment before writing Python code. This section covers installing Python, choosing a code editor, and configuring the workspace.

## Installing Python

Python runs on all major operating systems: Windows, macOS, and Linux.

### Windows Installation

1. Visit the official Python website: [python.org](https://python.org)
2. Download the latest Python 3.12+ installer for Windows
3. Run the installer
4. Check the box labeled "Add Python to PATH"
5. Click "Install Now"

We verify the installation by opening Command Prompt and running:

```bash
python --version
```

Expected output:

```
Python 3.12.0
```

### macOS Installation

macOS comes with Python pre-installed, but often an older version. We install the latest version using Homebrew:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew install python
```

We verify with:

```bash
python3 --version
```

### Linux Installation

Most Linux distributions include Python. On Ubuntu or Debian:

```bash
sudo apt update
sudo apt install python3 python3-pip
```

We verify with:

```bash
python3 --version
```

## Installing pip

pip is Python's package manager. It lets us install libraries and tools from the Python community.

Python 3.4+ comes with pip bundled. We verify pip is installed:

```bash
pip --version
```

### Installing Your First Package

We install the `requests` library to verify everything works:

```bash
pip install requests
```

The `requests` library handles HTTP requests. We test the installation:

```python
import requests

response = requests.get("https://api.github.com")
print(f"Status: {response.status_code}")
print(f"Python package installation works!")
```

## Choosing a Code Editor

We need a text editor designed for coding. The best options:

### Visual Studio Code (Recommended)

VS Code is a free, lightweight editor with excellent Python support.

**Installation:**

1. Download from [code.visualstudio.com](https://code.visualstudio.com)
2. Install the Python extension:
   - Press `Ctrl+Shift+X` (Windows) or `Cmd+Shift+X` (macOS)
   - Search for "Python"
   - Click "Install" on the official Microsoft Python extension

**Key Features:**
- Syntax highlighting
- IntelliSense (code completion)
- Integrated terminal
- Debugging support

### PyCharm

PyCharm is a dedicated Python IDE with professional-grade features.

**Editions:**
- **Community** — Free, open-source
- **Professional** — Paid, with extra features for web development

### IDLE

IDLE comes bundled with Python. We launch it from terminal:

```bash
idle
```

### Editor Configuration

We configure every editor with these settings:

1. **Indent with spaces** (4 spaces per indent level)
2. **Line endings** — Use Unix-style (LF)
3. **Font** — Use a monospace font like Fira Code, Consolas, or Monaco

## Creating Your First Project

We create a structured project to organize Python code.

### Project Directory Structure

```
my-python-project/
    ├── src/
    │   └── main.py
    ├── tests/
    │   └── test_main.py
    ├── requirements.txt
    └── README.md
```

### Creating Directories

**Windows:**
```bash
mkdir my-python-project
cd my-python-project
mkdir src tests
```

**macOS/Linux:**
```bash
mkdir -p my-python-project/src my-python-project/tests
cd my-python-project
```

### Creating requirements.txt

This file lists project dependencies:

```text
requests>=2.31.0
```

We install dependencies:

```bash
pip install -r requirements.txt
```

## Virtual Environments

Virtual environments keep project dependencies isolated from other projects and the system.

### Why We Use Virtual Environments

- **Isolation** — Different projects use different library versions
- **Cleanliness** — No global system pollution
- **Reproducibility** — We recreate exact environments elsewhere easily

### Creating a Virtual Environment

**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**macOS/Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

The terminal prompt changes to show the active environment:

```
(venv) C:\Users\YourName\my-project>
```

### Installing Packages in the Virtual Environment

```bash
pip install requests
```

Now `requests` installs only in this virtual environment.

### Exiting the Virtual Environment

```bash
deactivate
```

## Running Python Code

We run Python code in multiple ways:

### Interactive Mode

We start the Python interpreter:

```bash
python
```

The interpreter shows:

```python
>>> print("Hello, Python!")
Hello, Python!
>>> 2 + 2
4
>>> name = "Python Learner"
>>> f"Welcome to {name}!"
'Welcome to Python Learner!'
```

### Running a Script

We create `hello.py`:

```python
def greet(name):
    return f"Hello, {name}! Welcome to Python."

if __name__ == "__main__":
    name = input("Enter your name: ")
    print(greet(name))
```

We run it:

```bash
python hello.py
```

### Using VS Code

1. Open the project folder in VS Code
2. Create a new file: `Ctrl+N` or `Cmd+N`
3. Save as `.py` file: `Ctrl+S` or `Cmd+S`
4. Run: Press `F5` to debug or `Ctrl+Enter` to run the current line

### Using the Terminal

```bash
python path/to/script.py
python3 path/to/script.py
```

### VS Code Settings

We create a `.vscode/settings.json` file:

```json
{
    "python.linting.enabled": true,
    "python.linting.pylintEnabled": true,
    "python.formatting.provider": "black",
    "python.testing.pytestEnabled": true,
    "editor.formatOnSave": true,
    "editor.tabSize": 4,
    "files.insertFinalNewline": true
}
```

- **Python** — Microsoft's official Python extension
- **Pylance** — Fast type checking and language server
- **Python Preview** — See output alongside code
- **GitLens** — Git integration

## Troubleshooting Common Issues

### "python is not recognized"

Python wasn't added to PATH. We re-run the installer and check "Add Python to PATH", or manually add Python to system PATH.

### "pip is not recognized"

We use:

```bash
python -m pip
```

### Wrong Python version

We check which Python is active:

```bash
where python  # Windows
```

We use `python3` explicitly:

```bash
python3 script.py
```

### Virtual Environment Problems on Windows

We enable script execution if blocked:

```bash
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

## Development Environment Checklist

Before moving on, we verify the setup:

- [ ] Python installed and working (`python --version`)
- [ ] pip working (`pip --version`)
- [ ] Code editor installed and configured
- [ ] Virtual environment creation working
- [ ] Simple script runs successfully

We save this test script as `test_setup.py`:

```python
import sys
import pip
import os

def test_environment():
    print(f"Python version: {sys.version}")
    print(f"Python executable: {sys.executable}")
    print(f"pip version: {pip.__version__}")
    print(f"Current directory: {os.getcwd()}")
    print("\nYour Python environment is ready!")

if __name__ == "__main__":
    test_environment()
```

We run the test:

```bash
python test_setup.py
```
