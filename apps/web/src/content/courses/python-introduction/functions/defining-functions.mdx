# Defining Functions

Functions are reusable blocks of code that perform a specific task. We define a function once and call it whenever we need it, avoiding repetition and organizing code into manageable pieces.

## Why Use Functions?

Functions help us:

- **Avoid repetition** — Write code once, use it many times
- **Organize code** — Break complex programs into manageable pieces
- **Improve readability** — Give meaningful names to operations
- **Easy testing** — Test individual functions independently

## Defining a Function

We define a function using the `def` keyword, followed by the function name and parentheses:

```python
def greet():
    print("Hello, welcome!")
```

This defines a function named `greet` that prints a greeting message when called.

## Calling a Function

We call a function by using its name followed by parentheses:

```python
def greet():
    print("Hello, welcome!")

greet()
```

Output:

```
Hello, welcome!
```

## Functions with Parameters

Parameters allow functions to accept input values:

```python
def greet(name):
    print(f"Hello, {name}!")

greet("Alice")
greet("Bob")
```

Output:

```
Hello, Alice!
Hello, Bob!
```

## The `return` Statement

We use the `return` keyword to send a value back to the caller:

```python
def add(a, b):
    return a + b

result = add(3, 5)
print(result)
```

Output:

```
8
```

If a function does not have a `return` statement, it returns `None` by default.

## Function Naming

We follow these conventions when naming functions:

- Use lowercase letters and underscores (`my_function`)
- Make names descriptive (`calculate_area` not `calc`)
- Avoid using Python keywords as names

## A Complete Example

The following example calculates the area of rectangles:

```python
def calculate_rectangle_area(width, height):
    """Calculate the area of a rectangle."""
    area = width * height
    return area

room_area = calculate_rectangle_area(10, 12)
garden_area = calculate_rectangle_area(15, 20)

print(f"Room area: {room_area} square meters")
print(f"Garden area: {garden_area} square meters")
```

Output:

```
Room area: 120 square meters
Garden area: 300 square meters
```

## Docstrings

We document functions using docstrings (triple-quoted strings inside the function):

```python
def greet(name):
    """
    Greet a person by name.

    Args:
        name: The name of the person to greet.

    Returns:
        A greeting string.
    """
    return f"Hello, {name}!"
```

Docstrings help other developers understand what our function does.

## Summary

- Use `def` keyword to define a function
- Function names should be descriptive and use snake_case
- Parameters allow functions to accept input
- Use `return` to send a value back to the caller
- Docstrings document what a function does
