# Defining Functions

Functions are reusable blocks of code that perform a specific task. Instead of writing the same code multiple times, you can define a function once and call it whenever you need it.

## Why Use Functions?

Functions help you:

- **Avoid repetition** — Write code once, use it many times
- **Organize code** — Break complex programs into manageable pieces
- **Improve readability** — Give meaningful names to operations
- **Easy testing** — Test individual functions independently

## Defining a Function

In Python, you define a function using the `def` keyword, followed by the function name and parentheses:

```python
def greet():
    print("Hello, welcome!")
```

This creates a function named `greet` that prints a greeting message when called.

## Calling a Function

To execute a function, you call it by using its name followed by parentheses:

```python
def greet():
    print("Hello, welcome!")

# Calling the function
greet()
```

Output:

```
Hello, welcome!
```

## Functions with Parameters

Functions become more useful when they can accept input values. These input values are called parameters:

```python
def greet(name):
    print(f"Hello, {name}!")

greet("Alice")
greet("Bob")
```

Output:

```
Hello, Alice!
Hello, Bob!
```

## The `return` Statement

Functions can return a value to the caller using the `return` keyword:

```python
def add(a, b):
    return a + b

result = add(3, 5)
print(result)
```

Output:

```
8
```

If a function doesn't have a `return` statement, it returns `None` by default.

## Function Naming

Follow these conventions when naming functions:

- Use lowercase letters and underscores (`my_function`)
- Make names descriptive (`calculate_area` not `calc`)
- Avoid using Python keywords as names

## A Complete Example

Here's a more complete example that combines what we've learned:

```python
def calculate_rectangle_area(width, height):
    """Calculate the area of a rectangle."""
    area = width * height
    return area

# Calculate areas for different rectangles
room_area = calculate_rectangle_area(10, 12)
garden_area = calculate_rectangle_area(15, 20)

print(f"Room area: {room_area} square meters")
print(f"Garden area: {garden_area} square meters")
```

Output:

```
Room area: 120 square meters
Garden area: 300 square meters
```

## Docstrings

You can add documentation to your functions using docstrings (triple-quoted strings inside the function):

```python
def greet(name):
    """
    Greet a person by name.

    Args:
        name: The name of the person to greet.

    Returns:
        A greeting string.
    """
    return f"Hello, {name}!"
```

Docstrings help other developers understand what your function does.

## Summary

- Use `def` keyword to define a function
- Function names should be descriptive and use snake_case
- Parameters allow functions to accept input
- Use `return` to send a value back to the caller
- Docstrings document what a function does
