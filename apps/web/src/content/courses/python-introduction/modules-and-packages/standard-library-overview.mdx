# Standard Library Overview

Python's standard library is a collection of modules that come bundled with every Python installation. These modules provide ready-to-use functionality for common programming tasks, so you do not need to write code from scratch for things like mathematical operations, random number generation, date handling, and data format conversion.

## Python's Built-in Modules Overview

The standard library contains over 200 modules covering a wide range of functionality. Some of the most frequently used categories include:

- Mathematical functions and constants (`math`, `statistics`)
- Random number generation (`random`)
- Date and time handling (`datetime`, `time`)
- File and directory operations (`os`, `pathlib`, `shutil`)
- Data format handling (`json`, `csv`, `xml`)
- Text pattern matching (`re`)
- System and program information (`sys`, `platform`)

You already learned about importing modules in the [Importing Modules](/courses/python-introduction/modules-and-packages/importing-modules) section. The same import syntax works for all standard library modules.

## The Math Module

The `math` module provides access to mathematical functions and constants. You import it just like any other module.

```python
import math
```

### Mathematical Functions

The `math` module includes functions for common calculations:

```python
import math

# Square root - finds the number that multiplied by itself equals the input
print(math.sqrt(25))

# Power - raises a number to an exponent (2^3 = 8)
print(math.pow(2, 3))

# Absolute value - returns the positive version of a number
print(math.abs(-7))

# Floor - rounds down to the nearest whole number
print(math.floor(4.7))

# Ceiling - rounds up to the nearest whole number
print(math.ceil(4.2))
```

The `sqrt` function calculates square roots. The `pow` function performs exponentiation. The `abs` function returns absolute values. The `floor` and `ceil` functions handle rounding. This outputs `5.0`, `8.0`, `7`, `4`, and `5`.

### Mathematical Constants

The `math` module also provides important constants:

```python
import math

print(math.pi)
print(math.e)
print(math.inf)
```

The constant `math.pi` represents the ratio of a circle's circumference to its diameter (approximately 3.14159). The constant `math.e` represents Euler's number, the base of natural logarithms (approximately 2.71828). The constant `math.inf` represents positive infinity, useful for comparisons.

## The Random Module

The `random` module generates pseudo-random numbers for simulations, games, and data sampling. Pseudo-random means the numbers appear random but are generated by a deterministic algorithm.

```python
import random
```

### Generating Random Numbers

```python
import random

# Random integer between 1 and 10 (inclusive)
print(random.randint(1, 10))

# Random integer between 0 and 9
print(random.randrange(10))

# Random float between 0 and 1
print(random.random())
```

The `randint` function returns a random integer between the two specified values, including both endpoints. The `randrange` function works like `randint` but excludes the endpoint. The `random` function returns a float between 0 (inclusive) and 1 (exclusive). Example output might be `7`, `3`, and `0.582`.

### Selecting from a Sequence

```python
import random

fruits = ["apple", "banana", "cherry", "date"]

# Pick a single random item
print(random.choice(fruits))

# Shuffle a list in place (randomizes the order)
cards = [1, 2, 3, 4, 5]
random.shuffle(cards)
print(cards)

# Pick multiple random items
print(random.sample(fruits, 2))
```

The `choice` function picks one random item from a sequence. The `shuffle` function randomizes the order of a list in place, meaning the original list is modified. The `sample` function picks multiple unique items without replacement. Example output might be `cherry`, `[3, 1, 5, 2, 4]`, and `['banana', 'date']`.

## The Datetime Module

The `datetime` module handles dates and times. It provides classes for working with dates, times, and combined date-times.

```python
import datetime
```

### Creating Dates and Times

```python
import datetime

# Current date
today = datetime.date.today()
print(today)

# Current date and time
now = datetime.datetime.now()
print(now)

# Create a specific date
birthday = datetime.date(1990, 5, 15)
print(birthday)

# Create a specific time
midnight = datetime.time(0, 0, 0)
print(midnight)
```

The `date.today()` function returns today's date. The `datetime.now()` function returns the current date and time with microsecond precision. You can create specific dates by passing year, month, and day to `date()`. You can create specific times by passing hour, minute, and second to `time()`.

### Date Arithmetic

```python
import datetime

today = datetime.date.today()
future = today + datetime.timedelta(days=30)
print(future)

# Calculate difference between dates
day1 = datetime.date(2024, 1, 1)
day2 = datetime.date(2024, 1, 15)
difference = day2 - day1
print(difference.days)
```

The `timedelta` class represents a duration, such as 30 days. Adding a timedelta to a date gives you a new date that many days in the future. Subtracting one date from another returns a timedelta, and the `.days` attribute gives you the number of days as an integer.

## The JSON Module for Data

JSON (JavaScript Object Notation) is a text format for storing and exchanging data. Python's `json` module converts between JSON strings and Python data structures.

```python
import json
```

### Converting Python to JSON

```python
import json

data = {
    "name": "Alice",
    "age": 30,
    "skills": ["Python", "JavaScript"]
}

json_string = json.dumps(data)
print(json_string)
```

The `dumps` function (dump string) converts a Python dictionary into a JSON string. The resulting string is valid JSON that other languages can parse. Output looks like: `{"name": "Alice", "age": 30, "skills": ["Python", "JavaScript"]}`.

### Converting JSON to Python

```python
import json

json_string = '{"name": "Bob", "age": 25, "city": "New York"}'

data = json.loads(json_string)
print(data["name"])
print(data["city"])
```

The `loads` function (load string) parses a JSON string and converts it into a Python dictionary. You can then access the values using dictionary syntax.

### Reading and Writing JSON Files

```python
import json

# Write JSON to a file
data = {"username": "admin", "access_level": "admin"}
with open("config.json", "w") as file:
    json.dump(data, file, indent=2)

# Read JSON from a file
with open("config.json", "r") as file:
    loaded_data = json.load(file)
    print(loaded_data)
```

The `dump` function writes Python data to a file in JSON format. The `indent=2` parameter makes the output readable with two-space indentation. The `load` function reads a JSON file and returns the Python data structure.

## Practical Example: Random Password Generator

Combining what you have learned, you can build a password generator that creates random passwords:

```python
import random
import string

def generate_password(length=12):
    """Generate a random password with letters, digits, and symbols."""
    # Characters to choose from
    letters = string.ascii_letters
    digits = string.digits
    symbols = "!@#$%^&*"

    all_characters = letters + digits + symbols

    # Generate password by picking random characters
    password = []
    password.append(random.choice(letters))
    password.append(random.choice(digits))
    password.append(random.choice(symbols))

    for _ in range(length - 3):
        password.append(random.choice(all_characters))

    random.shuffle(password)
    return ''.join(password)

print(generate_password(16))
print(generate_password())
```

The `string` module provides constants for character sets: `ascii_letters` contains all uppercase and lowercase letters, `ascii_digits` contains 0-9, and you define symbols manually. The function ensures the password contains at least one letter, one digit, and one symbol before filling the rest with random characters. The `''.join(password)` converts the list of characters into a single string.

This might output something like `xK9#mP2$vL7@qT4` or `aG5!bC8^dE3`.
