# The while Loop

We use the `while` loop when we need to repeat code an unknown number of times, continuing as long as a condition remains true.

## Basic Syntax

```python
while condition:
    # code to execute while condition is true
```

Python checks the condition before each iteration. If it is true, we execute the block and check again. When the condition becomes false, the loop stops.

## Simple Example

```python
count = 0

while count < 5:
    print(count)
    count += 1
```

Output:
```
0
1
2
3
4
```

We initialize `count` to 0, then loop while `count < 5`. Each iteration prints the current value, then increments it. When `count` reaches 5, the condition is false and we exit.

## Loop with User Input

We use `while` loops to keep asking for input until we receive valid data:

```python
password = ""

while password != "secret":
    password = input("Enter the password: ")

print("Access granted!")
```

This loops until the user types "secret".

## Infinite Loops

If the condition never becomes false, the loop runs forever. We must ensure the condition will eventually be met:

```python
# This creates an infinite loop
# while True:
#     print("This runs forever")
```

To stop an infinite loop, press `Ctrl+C` in most terminals.

## Using a Flag

We control loop execution with a boolean flag when the stopping condition depends on events inside the loop:

```python
active = True
count = 0

while active:
    print(f"Count is {count}")
    count += 1

    if count >= 5:
        active = False

print("Loop ended")
```

Output:
```
Count is 0
Count is 1
Count is 2
Count is 3
Count is 4
Loop ended
```

## While with else

The `while` loop supports an `else` clause that runs when the condition becomes false:

```python
count = 0

while count < 3:
    print(count)
    count += 1
else:
    print("Condition became false - else block executed")
```

Output:
```
0
1
2
Condition became false - else block executed
```

## Breaking Out of a while Loop

We exit a `while` loop early using `break`:

```python
count = 0

while True:
    print(count)
    count += 1

    if count >= 5:
        break

print("Loop ended with break")
```

Output:
```
0
1
2
3
4
Loop ended with break
```

`break` exits the innermost loop immediately.

## Skipping Iterations with continue

We skip to the next iteration using `continue`, bypassing any code that remains in the current block:

```python
count = 0

while count < 5:
    count += 1

    if count == 3:
        continue

    print(count)
```

Output:
```
1
2
4
5
```

When `count` equals 3, we skip the `print` and continue to the next iteration.

## Practical Example: Guessing Game

We build a complete guessing game with `while`:

```python
import random

secret_number = random.randint(1, 10)
guess = 0
attempts = 0

print("I'm thinking of a number between 1 and 10...")

while guess != secret_number:
    guess = int(input("Take a guess: "))
    attempts += 1

    if guess < secret_number:
        print("Too low!")
    elif guess > secret_number:
        print("Too high!")
    else:
        print(f"Correct! You got it in {attempts} attempts!")
```

We loop until the guess matches the secret number. The loop tracks attempts and provides feedback after each guess.

## Practical Example: Menu-Driven Program

We create a menu system that runs until the user quits:

```python
choice = ""

while choice != "quit":
    print("\n--- Menu ---")
    print("1. Say hello")
    print("2. Say goodbye")
    print("3. Quit")

    choice = input("Enter your choice: ")

    if choice == "1":
        print("Hello, World!")
    elif choice == "2":
        print("Goodbye!")
    elif choice == "3":
        print("Thanks for using the menu!")
    else:
        print("Invalid choice, please try again.")
```

The loop continues as long as the user has not entered "quit".

## Summary

- `while` loops repeat as long as the condition is true
- We must update variables in the condition to avoid infinite loops
- `break` exits the loop immediately
- `continue` skips to the next iteration
- The `else` clause runs when the condition becomes false
- Flags help us control loops from inside the body
- We use `while` when we do not know the number of iterations in advance
