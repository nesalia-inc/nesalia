# If Statements

In Python, `if` statements allow you to execute code conditionally.

## Basic Syntax

```python
x = 10

if x > 5:
    print("x is greater than 5")
```

## If-Else

```python
x = 3

if x > 5:
    print("x is greater than 5")
else:
    print("x is not greater than 5")
```

## Elif

```python
x = 5

if x > 5:
    print("x is greater than 5")
elif x == 5:
    print("x is equal to 5")
else:
    print("x is less than 5")
```
