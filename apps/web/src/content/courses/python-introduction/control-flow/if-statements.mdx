# If Statements

We use `if` statements to execute code only when certain conditions are true.

## Basic Syntax

We write an `if` statement with a condition followed by a colon, then an indented code block:

```python
x = 10

if x > 5:
    print("x is greater than 5")
```

Output:
```
x is greater than 5
```

The condition `x > 5` evaluates to `True`, so we execute the `print` statement.

## If-Else

When the condition is false, we can execute an alternative block using `else`:

```python
x = 3

if x > 5:
    print("x is greater than 5")
else:
    print("x is not greater than 5")
```

Output:
```
x is not greater than 5
```

## Elif for Multiple Conditions

We chain conditions with `elif` (else-if) when we have more than two possibilities:

```python
x = 5

if x > 5:
    print("x is greater than 5")
elif x == 5:
    print("x is equal to 5")
else:
    print("x is less than 5")
```

Output:
```
x is equal to 5
```

Python evaluates each condition in order until one is true. If none are true, the `else` block runs.

## Logical Operators

We combine conditions using `and`, `or`, and `not`.

### Using `and`

Both conditions must be true:

```python
age = 25
income = 50000

if age >= 18 and income >= 30000:
    print("Loan approved")
else:
    print("Loan denied")
```

Output:
```
Loan approved
```

### Using `or`

At least one condition must be true:

```python
day = "Saturday"

if day == "Saturday" or day == "Sunday":
    print("It's the weekend")
else:
    print("It's a weekday")
```

Output:
```
It's the weekend
```

### Using `not`

We invert a boolean condition:

```python
is_raining = False

if not is_raining:
    print("We can go outside")
```

Output:
```
We can go outside
```

## Nested If Statements

We place `if` statements inside other `if` blocks when we need to check multiple conditions:

```python
age = 20
has_id = True

if age >= 18:
    print("Adult")
    if has_id:
        print("Can enter the venue")
    else:
        print("Need ID to enter")
else:
    print("Too young")
```

Output:
```
Adult
Can enter the venue
```

We indent nested blocks one level deeper than the parent block.

## Truthiness and Falsy Values

Every value in Python has a boolean equivalent. We often write conditions directly against values instead of comparing them to `True` or `False`:

```python
name = "Alice"
empty_list = []

if name:
    print(f"Hello, {name}")

if not empty_list:
    print("List is empty")
```

Output:
```
Hello, Alice
List is empty
```

Values that evaluate to false are called "falsy": `0`, `""`, `[]`, `{}`, `None`, `False`. All other values are "truthy".

## Practical Example: Grade Classification

We build a complete grade classification system:

```python
score = 87

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"

print(f"Score: {score} → Grade: {grade}")
```

Output:
```
Score: 87 → Grade: B
```

## Summary

- `if` executes code when its condition is true
- `elif` checks additional conditions after the initial `if`
- `else` runs when no previous condition was true
- `and` requires all conditions to be true
- `or` requires at least one condition to be true
- `not` inverts a boolean value
- We nest `if` statements by indenting further
- Values like `0`, `""`, `[]`, and `None` are falsy; most other values are truthy
