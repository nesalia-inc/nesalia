# The for Loop and range()

The `for` loop in Python is used to iterate over sequences such as lists, strings, or ranges. It allows you to execute a block of code repeatedly for each item in a sequence.

## Basic Syntax

```python
for item in sequence:
    # code to execute for each item
```

## Iterating Over a List

```python
fruits = ["apple", "banana", "cherry"]

for fruit in fruits:
    print(fruit)
```

Output:
```
apple
banana
cherry
```

## Using range()

The `range()` function generates a sequence of numbers. It is commonly used with `for` loops to repeat code a specific number of times.

### range(stop)

```python
for i in range(5):
    print(i)
```

Output:
```
0
1
2
3
4
```

### range(start, stop)

```python
for i in range(2, 6):
    print(i)
```

Output:
```
2
3
4
5
```

### range(start, stop, step)

```python
for i in range(0, 10, 2):
    print(i)
```

Output:
```
0
2
4
6
8
```

## Iterating Over a String

```python
for letter in "Python":
    print(letter)
```

Output:
```
P
y
t
h
o
n
```

## Using range() with len()

Often, you may need both the index and the value when iterating. You can combine `range()` with `len()`:

```python
colors = ["red", "green", "blue"]

for i in range(len(colors)):
    print(f"Index {i}: {colors[i]}")
```

Output:
```
Index 0: red
Index 1: green
Index 2: blue
```

## The enumerate() Function

While `range()` with `len()` works, `enumerate()` is a cleaner way to get both index and value:

```python
colors = ["red", "green", "blue"]

for index, color in enumerate(colors):
    print(f"Index {index}: {color}")
```

Output:
```
Index 0: red
Index 1: green
Index 2: blue
```

## Nested for Loops

You can nest `for` loops inside each other:

```python
for i in range(3):
    for j in range(2):
        print(f"({i}, {j})")
```

Output:
```
(0, 0)
(0, 1)
(1, 0)
(1, 1)
(2, 0)
(2, 1)
```

## Loop Else Clause

Python allows an optional `else` block that executes after the loop finishes normally (not interrupted by `break`):

```python
for i in range(3):
    print(i)
else:
    print("Loop completed successfully")
```

Output:
```
0
1
2
Loop completed successfully
```

## List Comprehensions

A concise way to create lists using `for` loops:

```python
squares = [x**2 for x in range(5)]
print(squares)
```

Output:
```
[0, 1, 4, 9, 16]
```

## Summary

- Use `for item in sequence` to iterate over any sequence
- `range(n)` generates numbers from 0 to n-1
- `range(start, stop)` generates numbers from start to stop-1
- `range(start, stop, step)` generates numbers with a custom step
- `enumerate()` provides both index and value in a single loop
