# The for Loop and range()

The `for` loop is a fundamental control structure in Python that allows you to repeat actions for each item in a sequence. When you need to perform the same operation on every element in a collection, the `for` loop is your go-to tool.

## What Does "Iterate" Mean?

To **iterate** means to repeat a process for each item in a collection, one after another. When you iterate over a **sequence** (such as a list, string, or range), you visit each element in order. The collection you can iterate over is called an **iterable**—it is any Python object capable of returning its members one at a time.

## Basic Syntax

```python
for item in sequence:
    # code to execute for each item
```

The `for` keyword starts the loop. The variable name (here called `item`) is called the **loop variable**. On each pass through the loop, Python assigns the next element from the sequence to this variable, then executes the indented code block. This process repeats until every item has been processed.

## Iterating Over a List

```python
fruits = ["apple", "banana", "cherry"]

for fruit in fruits:
    print(fruit)
```

Output:
```
apple
banana
cherry
```

In this example, you create a list called `fruits` containing three strings. The `for` loop then assigns `fruit` to each string in turn. On the first iteration, `fruit` holds `"apple"`. On the second, it holds `"banana"`. On the third, it holds `"cherry"`. After the last item, the loop ends automatically.

## Using range()

The `range()` function generates a sequence of numbers on demand, which is useful when you need to repeat code a specific number of times. Rather than creating a full list in memory, `range()` produces numbers as you need them—this is called **lazy evaluation**. The function returns an iterable that yields numbers in arithmetic progression.

### range(stop)

```python
for i in range(5):
    print(i)
```

Output:
```
0
1
2
3
4
```

When you call `range(5)`, it generates numbers starting from 0 and ending at 4 (it stops before reaching 5). This is common in programming because counting often begins at zero, a practice called **zero-based indexing**.

### range(start, stop)

```python
for i in range(2, 6):
    print(i)
```

Output:
```
2
3
4
5
```

By providing two arguments, you specify where the sequence should begin and end. Here, `range(2, 6)` generates numbers from 2 up to but not including 6. The first argument is called the **start** value, and the second is the **stop** value.

### range(start, stop, step)

```python
for i in range(0, 10, 2):
    print(i)
```

Output:
```
0
2
4
6
8
```

The third argument, called **step**, controls the interval between numbers. In this example, `range(0, 10, 2)` starts at 0 and increases by 2 each time, stopping before reaching 10. A negative step allows you to count backward.

## Iterating Over a String

Strings are sequences of characters, so you iterate over them the same way you iterate over lists:

```python
for letter in "Python":
    print(letter)
```

Output:
```
P
y
t
h
o
n
```

Each character, including the capital "P", becomes the loop variable `letter` in turn. The loop processes every character in the string from left to right.

## Using range() with len()

Sometimes you need both the index (position) and the value of each item. The `len()` function returns the number of elements in a sequence. By combining `range()` with `len()`, you generate valid index numbers:

```python
colors = ["red", "green", "blue"]

for i in range(len(colors)):
    print(f"Index {i}: {colors[i]}")
```

Output:
```
Index 0: red
Index 1: green
Index 2: blue
```

Here, `len(colors)` returns 3, and `range(3)` produces the indices 0, 1, and 2. You then use those indices to access the corresponding values from the list. This pattern is useful when you need to track positions or modify items in place.

## Nested for Loops

You can place one `for` loop inside another—this is called a **nested loop**. Use nested loops when you need to iterate over multiple dimensions, such as rows and columns in a grid:

```python
for i in range(3):
    for j in range(2):
        print(f"({i}, {j})")
```

Output:
```
(0, 0)
(0, 1)
(1, 0)
(1, 1)
(2, 0)
(2, 1)
```

The outer loop runs three times (for `i` equal to 0, 1, and 2). For each outer iteration, the inner loop runs twice (for `j` equal to 0 and 1). This produces 3 multiplied by 2, which equals 6 total iterations.

## Loop Else Clause

Python loops support an optional `else` block that runs after the loop completes all iterations without being interrupted by `break`. This is a unique Python feature:

```python
for i in range(3):
    print(i)
else:
    print("Loop completed successfully")
```

Output:
```
0
1
2
Loop completed successfully
```

The `else` block executes because the loop finished every iteration naturally. If you use `break` to exit the loop early, the `else` block will not run. This is often used for search operations where you want to check if an item was found or not.

For more on using `break` and `continue` to control loop execution, see [break-continue-pass](./break-continue-pass.mdx).

## List Comprehensions

A **list comprehension** is a concise way to create a list from a `for` loop in a single line. Instead of building a list step by step, you define the transformation directly. List comprehensions are considered Pythonic (idiomatic Python) and often run faster than equivalent loops.

```python
squares = [x**2 for x in range(5)]
print(squares)
```

Output:
```
[0, 1, 4, 9, 16]
```

Breaking this down: `x**2` is the expression applied to each item, `for x in range(5)` iterates over numbers 0 through 4, and the surrounding brackets `[]` collect the results into a list. For each number `x` in the range, Python computes `x**2` (x raised to the power of 2) and adds it to the new list.

You can also add conditions to filter items. This is called a **conditional list comprehension**:

```python
even_squares = [x**2 for x in range(10) if x % 2 == 0]
print(even_squares)
```

Output:
```
[0, 4, 16, 36, 64]
```

The `if x % 2 == 0` part keeps only even numbers (where the remainder when dividing by 2 is 0). The `%` operator is called the **modulo operator**, and it returns the remainder of division.

List comprehensions can also transform one type of data into another, such as converting a list of strings to uppercase:

```python
names = ["alice", "bob", "charlie"]
uppercase_names = [name.upper() for name in names]
print(uppercase_names)
```

Output:
```
['ALICE', 'BOB', 'CHARLIE']
```

While list comprehensions are powerful, avoid making them too complex. If your comprehension becomes difficult to read, consider using a regular `for` loop instead for clarity.

## How for Loops Differ from while Loops

The `for` loop and the `while` loop serve different purposes. A `for` loop iterates over a known sequence and completes when all items have been processed. A `while` loop repeats as long as a condition remains true, which makes it better suited for situations where you do not know how many iterations you need in advance.

For example, use a `for` loop when you have a fixed list of items. Use a `while` loop when you need to keep repeating until something changes, such as waiting for user input.

To learn more about `while` loops, see [while-loop](./while-loop.mdx).

## Summary

- The `for` loop iterates over any iterable (lists, strings, ranges, etc.)
- The **loop variable** holds the current item on each iteration
- `range(n)` produces numbers from 0 to n-1
- `range(start, stop)` produces numbers from start to stop-1
- `range(start, stop, step)` produces numbers with a custom interval
- `range()` with `len()` gives you both index and value
- Nested loops iterate over multiple dimensions by placing one loop inside another
- The `else` block runs when the loop finishes without `break`
- List comprehensions create lists inline using a concise `for` expression syntax
