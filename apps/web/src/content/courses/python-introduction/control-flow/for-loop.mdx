# The for Loop and range()

We use the `for` loop to iterate over any sequence: lists, strings, ranges, or other iterable objects.

## Basic Syntax

```python
for item in sequence:
    # code to execute for each item
```

The loop binds each item in the sequence to the variable name, then executes the block. We repeat this for every item in the sequence.

## Iterating Over a List

```python
fruits = ["apple", "banana", "cherry"]

for fruit in fruits:
    print(fruit)
```

Output:
```
apple
banana
cherry
```

On each iteration, `fruit` takes the value of the next item in the list.

## Using range()

We use `range()` to generate sequences of numbers. This is useful when we need to repeat code a specific number of times.

### range(stop)

```python
for i in range(5):
    print(i)
```

Output:
```
0
1
2
3
4
```

`range(5)` generates numbers from 0 up to but not including 5.

### range(start, stop)

```python
for i in range(2, 6):
    print(i)
```

Output:
```
2
3
4
5
```

We pass a start and stop to begin from a number other than 0.

### range(start, stop, step)

```python
for i in range(0, 10, 2):
    print(i)
```

Output:
```
0
2
4
6
8
```

The step argument controls the interval between numbers. Here we count by twos.

## Iterating Over a String

Strings are sequences of characters, so we iterate over them the same way:

```python
for letter in "Python":
    print(letter)
```

Output:
```
P
y
t
h
o
n
```

## Using range() with len()

When we need the index and value together, we combine `range()` with `len()`:

```python
colors = ["red", "green", "blue"]

for i in range(len(colors)):
    print(f"Index {i}: {colors[i]}")
```

Output:
```
Index 0: red
Index 1: green
Index 2: blue
```

`len(colors)` returns 3, and `range(3)` produces indices 0, 1, 2.

## Nested for Loops

We nest one `for` loop inside another when we need to iterate over multiple dimensions:

```python
for i in range(3):
    for j in range(2):
        print(f"({i}, {j})")
```

Output:
```
(0, 0)
(0, 1)
(1, 0)
(1, 1)
(2, 0)
(2, 1)
```

The outer loop runs three times. For each outer iteration, the inner loop runs twice.

## Loop Else Clause

Python loops support an optional `else` block that runs after the loop completes normally (not interrupted by `break`):

```python
for i in range(3):
    print(i)
else:
    print("Loop completed successfully")
```

Output:
```
0
1
2
Loop completed successfully
```

The `else` block executes because `break` never interrupted the loop.

## List Comprehensions

We use a concise syntax to create lists directly from `for` loops:

```python
squares = [x**2 for x in range(5)]
print(squares)
```

Output:
```
[0, 1, 4, 9, 16]
```

The expression `x**2` runs for each `x` in `range(5)`, and results accumulate into the list.

## Summary

- `for item in sequence` iterates over any sequence
- `range(n)` produces numbers 0 to n-1
- `range(start, stop)` produces numbers from start to stop-1
- `range(start, stop, step)` produces numbers with the given interval
- `range()` with `len()` gives us both index and value
- Nested loops iterate over multiple dimensions
- The `else` block runs when the loop finishes without `break`
- List comprehensions create lists inline in a single expression
