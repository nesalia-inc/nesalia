# Enumerate and zip

We use `enumerate()` and `zip()` to work more efficiently with iterables. `enumerate()` adds indices to items, and `zip()` combines multiple sequences element-wise.

## The enumerate() Function

`enumerate()` adds a counter to an iterable and returns tuples of (index, value). This lets us access both the position and the item in a single loop.

### Basic Syntax

```python
for index, value in enumerate(iterable):
    # code
```

### Basic Example

```python
fruits = ["apple", "banana", "cherry"]

for index, fruit in enumerate(fruits):
    print(f"{index}: {fruit}")
```

Output:
```
0: apple
1: banana
2: cherry
```

### Starting Index from 1

We pass `start=1` to begin counting from a number other than 0:

```python
fruits = ["apple", "banana", "cherry"]

for index, fruit in enumerate(fruits, start=1):
    print(f"{index}: {fruit}")
```

Output:
```
1: apple
2: banana
3: cherry
```

### Practical Example: Creating a Numbered List

We build an interactive numbered menu:

```python
items = ["First", "Second", "Third", "Fourth"]

print("Select an item:")
for index, item in enumerate(items, start=1):
    print(f"  {index}. {item}")

choice = int(input("Enter your choice: "))
if 1 <= choice <= len(items):
    print(f"You selected: {items[choice - 1]}")
```

Output:
```
Select an item:
  1. First
  2. Second
  3. Third
  4. Fourth
```

## The zip() Function

`zip()` combines multiple iterables element-wise into tuples. It produces tuples containing corresponding elements from each input.

### Basic Syntax

```python
for item1, item2 in zip(iterable1, iterable2):
    # code
```

### Basic Example

```python
names = ["Alice", "Bob", "Charlie"]
ages = [25, 30, 35]

for name, age in zip(names, ages):
    print(f"{name} is {age} years old")
```

Output:
```
Alice is 25 years old
Bob is 30 years old
Charlie is 35 years old
```

### Combining Three Iterables

We zip more than two sequences by passing additional arguments:

```python
names = ["Alice", "Bob", "Charlie"]
ages = [25, 30, 35]
cities = ["New York", "London", "Paris"]

for name, age, city in zip(names, ages, cities):
    print(f"{name} ({age}) from {city}")
```

Output:
```
Alice (25) from New York
Bob (30) from London
Charlie (35) from Paris
```

### Different Length Iterables

`zip()` stops when the shortest iterable is exhausted. Extra elements in longer iterables are ignored:

```python
names = ["Alice", "Bob", "Charlie"]
scores = [95, 88]  # Only 2 items

for name, score in zip(names, scores):
    print(f"{name}: {score}")
```

Output:
```
Alice: 95
Bob: 88
```

"Charlie" has no corresponding score, so it is not included.

## Practical Examples

### Creating a Dictionary from Two Lists

We pair keys with values to build a dictionary:

```python
keys = ["name", "age", "city"]
values = ["Alice", 25, "New York"]

person = dict(zip(keys, values))
print(person)
```

Output:
```
{'name': 'Alice', 'age': 25, 'city': 'New York'}
```

`zip()` creates tuples of key-value pairs, and `dict()` converts them into a dictionary.

### Finding Corresponding Elements

We process corresponding elements from multiple lists together:

```python
list1 = [1, 2, 3, 4, 5]
list2 = [10, 20, 30, 40, 50]

print("Sums:")
for a, b in zip(list1, list2):
    print(f"  {a} + {b} = {a + b}")
```

Output:
```
Sums:
  1 + 10 = 11
  2 + 20 = 22
  3 + 30 = 33
  4 + 40 = 44
  5 + 50 = 55
```

### Iterating Over Multiple Sequences with enumerate

We combine `enumerate()` and `zip()` to work with multiple sequences while tracking indices:

```python
products = ["Laptop", "Mouse", "Keyboard"]
prices = [999, 29, 79]
stock = [10, 50, 30]

print("Inventory:")
for index, (product, price, qty) in enumerate(zip(products, prices, stock)):
    total = price * qty
    print(f"{index + 1}. {product}: ${price} x {qty} = ${total}")
```

Output:
```
Inventory:
1. Laptop: $999 x 10 = $9990
2. Mouse: $29 x 50 = $1450
3. Keyboard: $79 x 30 = $2370
```

### Transposing Data with zip

We transpose rows to columns by unpacking with `*`:

```python
data = [
    ["Alice", "Bob", "Charlie"],
    [25, 30, 35],
    ["New York", "London", "Paris"]
]

# Transpose rows to columns
for name, age, city in zip(*data):
    print(f"{name} ({age}) from {city}")
```

Output:
```
Alice (25) from New York
Bob (30) from London
Charlie (35) from Paris
```

`zip(*data)` treats each sublist as a column and zips them together as rows.

## Converting to Lists

`enumerate()` and `zip()` return iterator objects. To materialize them into a list, we wrap them with `list()`:

```python
fruits = ["apple", "banana", "cherry"]

# List of tuples
enum_list = list(enumerate(fruits))
print(enum_list)
```

Output:
```
[(0, 'apple'), (1, 'banana'), (2, 'cherry')]
```

```python
names = ["Alice", "Bob"]
ages = [25, 30]

zip_list = list(zip(names, ages))
print(zip_list)
```

Output:
```
[('Alice', 25), ('Bob', 30)]
```

## Using with List Comprehensions

We use `enumerate()` and `zip()` inside list comprehensions to create transformed lists:

```python
# Create a list of squares with their indices
numbers = [1, 2, 3, 4, 5]
squares_with_index = [(i, n**2) for i, n in enumerate(numbers)]
print(squares_with_index)
```

Output:
```
[(0, 1), (1, 4), (2, 9), (3, 16), (4, 25)]
```

```python
# Create a list of full names from first and last names
first_names = ["John", "Jane", "Jim"]
last_names = ["Doe", "Smith", "Brown"]

full_names = [f"{first} {last}" for first, last in zip(first_names, last_names)]
print(full_names)
```

Output:
```
['John Doe', 'Jane Smith', 'Jim Brown']
```

## Summary

- `enumerate()` yields (index, value) tuples for any iterable
- `zip()` combines multiple iterables element-wise into tuples
- Both return iterators; wrap with `list()` to materialize
- The `start` parameter in `enumerate()` changes the starting index
- `zip()` stops when the shortest iterable is exhausted
- Combining these functions lets us handle complex iteration patterns cleanly
