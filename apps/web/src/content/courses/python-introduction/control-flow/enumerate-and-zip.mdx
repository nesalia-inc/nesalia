# Enumerate and zip

You use `enumerate()` and `zip()` to work more efficiently with iterables in Python. `enumerate()` adds indices to items, and `zip()` combines multiple sequences element-wise. These functions are commonly used inside `for` loops (see [The for Loop and range()](./for-loop.mdx) for foundational loop concepts).

## Key Concepts

Before diving into the functions, here are some important terms:

- **Iterable**: Any Python object that you can loop over, such as a list, string, or tuple. An iterable produces items one at a time when you iterate over it.
- **Iterator**: An object that produces items on demand from an iterable. Both `enumerate()` and `zip()` return iterators, not lists.
- **Tuple**: An immutable (unchangeable) ordered sequence of values, written with parentheses like `(0, 'apple')`. Tuples often represent pairs or records of related data.

## The enumerate() Function

`enumerate()` adds a counter to an iterable and returns an iterator of tuples. Each tuple contains two values: the index and the corresponding item from the original iterable. This lets you access both the position and the item in a single loop.

### Basic Syntax

```python
for index, value in enumerate(iterable):
    # code
```

The loop unpacks each tuple into two variables: the index and the value. This is called tuple unpacking.

### Basic Example

```python
fruits = ["apple", "banana", "cherry"]

for index, fruit in enumerate(fruits):
    print(f"{index}: {fruit}")
```

Output:
```
0: apple
1: banana
2: cherry
```

The `enumerate()` function wraps the original list and yields tuples of `(index, value)` on each iteration. In this example, the first iteration produces `(0, 'apple')`, the second produces `(1, 'banana')`, and so on.

### Starting Index from 1

By default, `enumerate()` starts counting from 0. You can change this by passing a `start` parameter:

```python
fruits = ["apple", "banana", "cherry"]

for index, fruit in enumerate(fruits, start=1):
    print(f"{index}: {fruit}")
```

Output:
```
1: apple
2: banana
3: cherry
```

The `start` parameter is useful when you want user-friendly numbering that begins at 1 instead of 0.

### Practical Example: Displaying a Numbered Menu

Interactive programs often need numbered menus. You can use `enumerate()` with `start=1` to display a clean menu:

```python
menu_items = ["New Game", "Load Game", "Settings", "Quit"]

print("Main Menu:")
for index, item in enumerate(menu_items, start=1):
    print(f"  {index}. {item}")

choice = int(input("Enter your choice: "))
if 1 <= choice <= len(menu_items):
    print(f"You selected: {menu_items[choice - 1]}")
```

Output:
```
Main Menu:
  1. New Game
  2. Load Game
  3. Settings
  4. Quit
```

This pattern is common in CLI applications where users select options by number. The `choice - 1` calculation converts the 1-based user input back to a 0-based list index.

## The zip() Function

`zip()` combines multiple iterables element-wise and returns an iterator of tuples. Each tuple contains one item from each input sequence, paired by their positions.

### Basic Syntax

```python
for item1, item2 in zip(iterable1, iterable2):
    # code
```

You can zip together two or more iterables. On each iteration, `zip()` produces a tuple with one item from each iterable at the same position.

### Basic Example

```python
names = ["Alice", "Bob", "Charlie"]
ages = [25, 30, 35]

for name, age in zip(names, ages):
    print(f"{name} is {age} years old")
```

Output:
```
Alice is 25 years old
Bob is 30 years old
Charlie is 35 years old
```

The first tuple produced is `('Alice', 25)`, the second is `('Bob', 30)`, and the third is `('Charlie', 35)`. The function pairs elements at matching positions.

### Combining Three or More Iterables

You can pass any number of iterables to `zip()`. Each tuple in the result will contain one element from each iterable:

```python
names = ["Alice", "Bob", "Charlie"]
ages = [25, 30, 35]
cities = ["New York", "London", "Paris"]

for name, age, city in zip(names, ages, cities):
    print(f"{name} ({age}) from {city}")
```

Output:
```
Alice (25) from New York
Bob (30) from London
Charlie (35) from Paris
```

The three input lists are zipped together so that elements at index 0 from all lists form the first tuple, elements at index 1 form the second tuple, and so on.

### Different Length Iterables

When you zip iterables of different lengths, `zip()` stops when the shortest iterable is exhausted. Extra elements in longer iterables are silently ignored:

```python
names = ["Alice", "Bob", "Charlie"]
scores = [95, 88]  # Only 2 items

for name, score in zip(names, scores):
    print(f"{name}: {score}")
```

Output:
```
Alice: 95
Bob: 88
```

Only two tuples are produced because the `scores` list has only two elements. "Charlie" has no corresponding score, so it is not included in the output. This behavior is important to remember when your input lists might have different lengths.

## Practical Examples

### Creating a Dictionary from Two Lists

You can combine `zip()` with the `dict()` constructor to build a dictionary from separate key and value lists. This is a common way to create mappings in Python:

```python
config_keys = ["username", "theme", "language"]
config_values = ["alice", "dark", "English"]

settings = dict(zip(config_keys, config_values))
print(settings)
```

Output:
```
{'username': 'alice', 'theme': 'dark', 'language': 'English'}
```

The `zip()` function creates tuples like `('username', 'alice')`, and `dict()` converts these key-value tuples into a proper dictionary. This pattern is useful when you load configuration data from a file or API that separates keys from values.

### Processing Corresponding Elements

When you need to perform calculations between corresponding elements of multiple lists, `zip()` lets you handle them together:

```python
product_ids = ["A001", "A002", "A003", "A004", "A005"]
prices = [29.99, 49.99, 99.99, 149.99, 9.99]
quantities = [3, 1, 2, 1, 10]

print("Order Summary:")
for id, price, qty in zip(product_ids, prices, quantities):
    subtotal = price * qty
    print(f"  {id}: ${price:.2f} x {qty} = ${subtotal:.2f}")
```

Output:
```
Order Summary:
  A001: $29.99 x 3 = $89.97
  A002: $49.99 x 1 = $49.99
  A003: $99.99 x 2 = $199.98
  A004: $149.99 x 1 = $149.99
  A005: $9.99 x 10 = $99.90
```

This example simulates an order processing system where you calculate line-item totals. The `zip()` function pairs each product with its price and quantity, making the loop clean and readable.

### Iterating Over Multiple Sequences with enumerate

You can nest `enumerate()` inside `zip()` to get both indices and values from multiple sequences simultaneously:

```python
products = ["Wireless Mouse", "Mechanical Keyboard", "USB Hub"]
prices = [29.99, 89.99, 24.99]
stock = [45, 12, 30]

print("Product Catalog:")
for index, (product, price, qty) in enumerate(zip(products, prices, stock), start=1):
    print(f"{index}. {product}")
    print(f"   Price: ${price:.2f} | In Stock: {qty}")
```

Output:
```
Product Catalog:
1. Wireless Mouse
   Price: $29.99 | In Stock: 45
2. Mechanical Keyboard
   Price: $89.99 | In Stock: 12
3. USB Hub
   Price: $24.99 | In Stock: 30
```

The outer `enumerate()` provides sequential numbering, while the inner `zip()` unpacks three lists simultaneously. The parentheses around `(product, price, qty)` are required for nested tuple unpacking.

### Transposing Data with zip

**Transpose** means converting rows into columns, or vice versa. When you have data organized as rows (each sublist is a row), `zip()` with the unpacking operator `*` can convert it to column-oriented data. This is a common operation when working with tabular data:

```python
# Data organized as rows: each sublist is a row
spreadsheet = [
    ["Name", "Age", "City"],
    ["Alice", "28", "New York"],
    ["Bob", "34", "London"],
    ["Charlie", "25", "Paris"]
]

# Transpose rows to columns
header, *rows = spreadsheet
for name, age, city in zip(*rows):
    print(f"{name} ({age}) - {city}")
```

Output:
```
Alice (28) - New York
Bob (34) - London
Charlie (25) - Paris
```

The expression `zip(*rows)` uses the unpacking operator `*` to treat each sublist as a separate column rather than a row. So instead of pairing elements within each row, `zip()` pairs elements across rows at the same position. The first tuple becomes `("Alice", "Bob", "Charlie")`, which then unpacks into three separate variables.

## Understanding What enumerate() and zip() Return

Both `enumerate()` and `zip()` return **iterator objects**, not lists. An iterator is a lazy object that computes values on demand as you loop over it. This is memory-efficient because it does not store all values upfront.

### Converting to Lists

If you need to materialize the results into a list, wrap the function call with `list()`:

```python
fruits = ["mango", "papaya", "kiwi"]

enum_result = list(enumerate(fruits))
print(enum_result)
```

Output:
```
[(0, 'mango'), (1, 'papaya'), (2, 'kiwi')]
```

Each tuple contains the index and the corresponding value from the original list. Converting to a list is useful when you need to inspect the data or pass it to functions that require list input.

```python
first_names = ["John", "Jane"]
last_names = ["Doe", "Smith"]

zip_result = list(zip(first_names, last_names))
print(zip_result)
```

Output:
```
[('John', 'Doe'), ('Jane', 'Smith')]
```

The list contains tuples pairing corresponding elements from both input lists. The first tuple pairs "John" with "Doe", and the second pairs "Jane" with "Smith".

## Using with List Comprehensions

List comprehensions (see [The for Loop and range()](./for-loop.mdx) for more on comprehensions) work seamlessly with `enumerate()` and `zip()`. You can use them to create transformed lists in a single expression:

```python
temperatures = [72, 68, 75, 70, 74]

# Create tuples of (index, temperature in Celsius)
temps_with_index = [(i, (t - 32) * 5 / 9) for i, t in enumerate(temperatures)]
print(temps_with_index)
```

Output:
```
[(0, 22.22...), (1, 20.0), (2, 23.88...), (3, 21.11...), (4, 23.33...)]
```

The list comprehension iterates over `enumerate(temperatures)`, unpacking each tuple into an index and Fahrenheit value, then converts each temperature to Celsius while preserving the index.

```python
first_names = ["Emma", "Liam", "Olivia"]
last_names = ["Wilson", "Garcia", "Taylor"]

full_names = [f"{first} {last}" for first, last in zip(first_names, last_names)]
print(full_names)
```

Output:
```
['Emma Wilson', 'Liam Garcia', 'Olivia Taylor']
```

The list comprehension zips two lists together and combines each pair of names into a full name string. This is a compact alternative to a `for` loop with concatenation.

## Summary

- `enumerate()` returns an iterator of `(index, value)` tuples, adding a counter to any iterable
- `zip()` returns an iterator of tuples, combining corresponding elements from multiple iterables
- Both functions return iterators, not lists; wrap with `list()` to materialize if needed
- The `start` parameter in `enumerate()` changes the starting index (defaults to 0)
- `zip()` stops when the shortest iterable is exhausted; extra elements are ignored
- Combining `enumerate()` and `zip()` lets you handle complex iteration patterns
- Tuple unpacking makes it easy to work with the results in `for` loops
