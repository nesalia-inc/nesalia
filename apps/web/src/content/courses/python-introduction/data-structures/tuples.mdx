# Tuples and Immutability

We use tuples when we need an ordered collection that cannot be modified after creation. Tuples are immutable, which provides data protection and slight performance benefits over lists.

## Creating Tuples

We create tuples using parentheses or plain commas:

```python
# Empty tuple
empty_tuple = ()

# Tuple with values
coordinates = (10, 20)
colors = ("red", "green", "blue")

# Single element tuple requires a trailing comma
single = (42,)  # The comma is required!

# Tuple without parentheses (packing)
point = 10, 20

# Creating from other iterables
tuple_from_list = tuple([1, 2, 3])
tuple_from_string = tuple("hello")  # ('h', 'e', 'l', 'l', 'o')
```

## Accessing Elements

Tuples support the same indexing as lists. Zero-indexed access and negative indexing work identically:

```python
person = ("Alice", 25, "Engineer")

print(person[0])     # Alice
print(person[1])     # 25
print(person[-1])    # Engineer
print(person[-2])    # 25

# Slicing works the same as lists
print(person[1:3])   # (25, 'Engineer')
```

## Why Use Tuples?

Tuples offer several advantages that make them the right choice in certain situations.

### Immutability

Tuples cannot be modified after creation:

```python
dimensions = (1920, 1080)

# We cannot modify: dimensions[0] = 2560 raises TypeError

# We only reassign the entire variable
dimensions = (2560, 1440)
```

### Performance

Tuples use less memory and access faster than lists:

```python
import sys

my_list = [1, 2, 3, 4, 5]
my_tuple = (1, 2, 3, 4, 5)

print(sys.getsizeof(my_list))   # Larger memory footprint
print(sys.getsizeof(my_tuple))  # Smaller memory footprint
```

### Dictionary Keys

Because tuples are immutable, we use them as dictionary keys:

```python
locations = {
    ("New York", "USA"): "NYC",
    ("Tokyo", "Japan"): "Tokyo",
    ("London", "UK"): "London"
}

print(locations[("New York", "USA")])  # NYC
```

### Multiple Return Values

Functions return tuples to provide multiple values:

```python
def get_stats(numbers):
    return min(numbers), max(numbers), sum(numbers)

stats = get_stats([1, 2, 3, 4, 5])
print(stats)  # (1, 5, 15)

# Unpack the tuple
minimum, maximum, total = get_stats([1, 2, 3, 4, 5])
print(f"Min: {minimum}, Max: {maximum}, Total: {total}")
```

## Tuple Operations

### Concatenation

```python
tuple1 = (1, 2, 3)
tuple2 = (4, 5, 6)
combined = tuple1 + tuple2  # (1, 2, 3, 4, 5, 6)
```

### Repetition

```python
repeated = ("Hi",) * 3  # ('Hi', 'Hi', 'Hi')
```

### Membership Testing

```python
colors = ("red", "green", "blue")

print("red" in colors)        # True
print("yellow" not in colors)  # True
```

### Iteration

```python
for color in ("red", "green", "blue"):
    print(color)
```

## Tuple Methods

Tuples have exactly two built-in methods due to their immutability.

### Counting Occurrences

```python
values = (1, 2, 2, 3, 2, 4, 2)

print(values.count(2))  # 3 (number of times 2 appears)
```

### Finding Index

```python
values = (1, 2, 3, 4, 5)

print(values.index(3))      # 2 (first index of value 3)
print(values.index(2, 3))    # 4 (start searching from index 3)
```

## Tuple Packing and Unpacking

### Packing

We pack values into a tuple:

```python
point = 10, 20, 30  # Packing into a tuple
```

### Unpacking

We unpack tuples into variables:

```python
point = (10, 20, 30)
x, y, z = point

print(x)  # 10
print(y)  # 20
print(z)  # 30
```

### Extended Unpacking

We use the star operator for extended unpacking:

```python
head, *body, tail = (1, 2, 3, 4, 5)

print(head)  # 1
print(body)   # [2, 3, 4]
print(tail)   # 5
```

## Named Tuples

Named tuples provide field access by name while maintaining tuple properties:

```python
from collections import namedtuple

# Define a named tuple type
Point = namedtuple('Point', ['x', 'y', 'z'])

# Create instances
point1 = Point(10, 20, 30)
point2 = Point(x=5, y=15, z=25)

# Access by index or name
print(point1[0])   # 10
print(point1.x)    # 10
print(point2.y)    # 15

# Named tuples are still tuples
print(point1 == point2)  # False
x, y, z = point1  # Unpacking still works
```

## Comparing Tuples

Tuples compare element-by-element:

```python
# Lexicographic comparison
print((1, 2, 3) < (1, 3, 2))   # True (2 < 3 at second position)
print((1, 2, 3) < (1, 2, 4))   # True (3 < 4 at third position)
print((1, 2, 3) == (1, 2, 3))  # True

# Sorting student records by grade
students = [("Alice", 85), ("Bob", 92), ("Charlie", 78)]
sorted_students = sorted(students)
print(sorted_students)  # [('Alice', 85), ('Bob', 92), ('Charlie', 78)]
```

## Converting Between Lists and Tuples

```python
# List to tuple
my_list = [1, 2, 3]
my_tuple = tuple(my_list)
print(my_tuple)  # (1, 2, 3)

# Tuple to list
my_tuple = (1, 2, 3)
my_list = list(my_tuple)
print(my_list)  # [1, 2, 3]
```

## Practical Examples

### Example 1: Swapping Variables

```python
# Traditional approach requires a temporary variable
a, b = 5, 10
temp = a
a = b
b = temp

# Tuple unpacking swaps without a temporary variable
a, b = 5, 10
a, b = b, a
print(f"a: {a}, b: {b}")  # a: 10, b: 5
```

### Example 2: Returning Multiple Values from a Function

```python
def divide(a, b):
    quotient = a // b
    remainder = a % b
    return quotient, remainder

q, r = divide(17, 5)
print(f"17 divided by 5: quotient = {q}, remainder = {r}")
```

### Example 3: Using Tuples as Dictionary Keys for Configuration

```python
# Store configuration settings with compound keys
settings = {
    ("database", "host"): "localhost",
    ("database", "port"): 5432,
    ("server", "ip"): "127.0.0.1",
    ("server", "port"): 8000
}

# Retrieve values
db_host = settings[("database", "host")]
print(f"Database host: {db_host}")
```

### Example 4: Coordinating Multiple Iterables

```python
# Process multiple sequences together
names = ["Alice", "Bob", "Charlie"]
ages = [25, 30, 35]
cities = ["NYC", "LA", "Chicago"]

for name, age, city in zip(names, ages, cities):
    print(f"{name} is {age} and lives in {city}")

# Build a lookup table from parallel lists
lookup = dict(zip(names, cities))
print(lookup)  # {'Alice': 'NYC', 'Bob': 'LA', 'Charlie': 'Chicago'}
```

### Example 5: Representing Fixed Data

```python
# RGB color definition (immutable)
rgb_red = (255, 0, 0)
rgb_green = (0, 255, 0)
rgb_blue = (0, 0, 255)

# Geographic coordinates
capital_cities = {
    ("USA", "Washington"): (38.8951, -77.0364),
    ("France", "Paris"): (48.8566, 2.3522),
    ("Japan", "Tokyo"): (35.6762, 139.6503)
}
```

## Tuples vs Lists Comparison

| Feature | Tuple | List |
|---------|-------|------|
| Syntax | `(1, 2, 3)` | `[1, 2, 3]` |
| Mutability | Immutable | Mutable |
| Performance | Faster, less memory | Slower, more memory |
| Methods | 2 methods | Many methods |
| Dictionary keys | Yes | No |
| Hashable | Yes | No |

We use tuples for fixed collections such as coordinates, configuration settings, return values from functions, and dictionary keys. We reserve lists for collections that change during program execution.
