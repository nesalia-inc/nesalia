# Sets and Set Operations

We use sets when we need an unordered collection containing only unique elements. Sets excel at eliminating duplicates and performing mathematical operations like union, intersection, and difference.

## Creating Sets

We create sets using curly braces or the set() constructor:

```python
# Empty set requires set() - {} creates a dictionary
empty_set = set()

# Set with values
colors = {"red", "green", "blue"}

# Set from a list (duplicates removed automatically)
numbers = set([1, 2, 2, 3, 3, 4])
print(numbers)  # {1, 2, 3, 4}

# Set from a string (unique characters)
letters = set("hello")
print(letters)  # {'h', 'e', 'l', 'o'}
```

## Key Properties of Sets

### Unordered

Sets maintain no particular order for elements:

```python
my_set = {3, 1, 4, 1, 5, 9, 2, 6}
print(my_set)  # {1, 2, 3, 4, 5, 6, 9} - order may vary
```

### Unique Elements

Sets automatically enforce uniqueness:

```python
items = {1, 2, 2, 3, 3, 3, 4, 4, 4}
print(items)  # {1, 2, 3, 4}
```

### Immutable Elements Only

Sets only accept immutable (hashable) elements:

```python
# Valid: numbers, strings, tuples
valid_set = {1, "hello", (1, 2, 3)}

# Invalid: lists, dictionaries, other sets raise TypeError
# invalid_set = {[1, 2, 3]}  # TypeError!
```

## Adding and Removing Elements

```python
fruits = {"apple", "banana"}

# Add a single element
fruits.add("cherry")

# Add multiple elements
fruits.update(["orange", "grape"])

# Remove an element (raises KeyError if not found)
fruits.remove("banana")

# Remove an element (does not raise error if not found)
fruits.discard("mango")

# Remove and return a random element
popped = fruits.pop()

# Clear all elements
fruits.clear()

print(fruits)  # set()
```

## Membership Testing

Sets provide O(1) lookup performance:

```python
numbers = {1, 2, 3, 4, 5}

print(3 in numbers)       # True
print(10 not in numbers)  # True

# Lookup remains fast even for large sets
large_set = set(range(1000000))
print(500000 in large_set)  # Very fast lookup
```

## Set Operations

### Union

We combine all elements from multiple sets:

```python
set1 = {1, 2, 3}
set2 = {3, 4, 5}

# Using | operator
union = set1 | set2

# Using union() method
union = set1.union(set2)

print(union)  # {1, 2, 3, 4, 5}
```

### Intersection

We find common elements between sets:

```python
set1 = {1, 2, 3, 4}
set2 = {3, 4, 5, 6}

# Using & operator
intersection = set1 & set2

# Using intersection() method
intersection = set1.intersection(set2)

print(intersection)  # {3, 4}
```

### Difference

We find elements in one set but not another:

```python
set1 = {1, 2, 3, 4}
set2 = {3, 4, 5, 6}

# Using - operator
difference = set1 - set2

# Using difference() method
difference = set1.difference(set2)

print(difference)  # {1, 2}
```

### Symmetric Difference

We find elements in either set but not both:

```python
set1 = {1, 2, 3, 4}
set2 = {3, 4, 5, 6}

# Using ^ operator
sym_diff = set1 ^ set2

# Using symmetric_difference() method
sym_diff = set1.symmetric_difference(set2)

print(sym_diff)  # {1, 2, 5, 6}
```

## Set Methods for Comparisons

### Subset

We check if all elements of one set exist in another:

```python
a = {1, 2}
b = {1, 2, 3, 4}

print(a.issubset(b))  # True
print(a <= b)        # True

# Proper subset (strictly less than)
print(a < b)          # True
print(b < b)          # False
```

### Superset

We check if a set contains all elements of another:

```python
a = {1, 2, 3, 4}
b = {1, 2}

print(a.issuperset(b))  # True
print(a >= b)            # True

# Proper superset
print(a > b)              # True
print(a > a)              # False
```

### Disjoint

We check if sets share no common elements:

```python
a = {1, 2, 3}
b = {4, 5, 6}
c = {3, 4, 5}

print(a.isdisjoint(b))  # True (no common elements)
print(a.isdisjoint(c))  # False (3 is in both)
```

## Iterating Over Sets

```python
fruits = {"apple", "banana", "cherry"}

# Basic iteration
for fruit in fruits:
    print(fruit)

# Enumerate (order not guaranteed)
for index, fruit in enumerate(fruits):
    print(f"{index}: {fruit}")
```

## Set Comprehensions

```python
# Basic set comprehension
squares = {x**2 for x in range(10)}
print(squares)  # {0, 1, 4, 9, 16, 25, 36, 49, 64, 81}

# With condition
even_squares = {x**2 for x in range(10) if x % 2 == 0}
print(even_squares)  # {0, 4, 16, 36, 64}
```

## Converting Between Sets and Other Collections

```python
# List to set removes duplicates
my_list = [1, 2, 2, 3, 3, 3]
my_set = set(my_list)
print(my_set)  # {1, 2, 3}

# Set to list
my_set = {1, 2, 3}
my_list = list(my_set)
print(my_list)  # [1, 2, 3] (order not guaranteed)

# String to set (unique characters)
my_set = set("hello")
print(my_set)  # {'h', 'e', 'l', 'o'}
```

## Practical Examples

### Example 1: Removing Duplicates from a List

```python
# Remove duplicates (order not preserved)
def remove_duplicates(items):
    return list(set(items))

numbers = [1, 2, 2, 3, 3, 3, 4, 4, 5]
unique = remove_duplicates(numbers)
print(unique)  # May not preserve order: [1, 2, 3, 4, 5]

# Remove duplicates while preserving order
def remove_duplicates_ordered(items):
    return list(dict.fromkeys(items))

unique_ordered = remove_duplicates_ordered(numbers)
print(unique_ordered)  # [1, 2, 3, 4, 5]
```

### Example 2: Finding Common and Unique Elements Between Lists

```python
# Find common elements between two lists
list1 = ["apple", "banana", "cherry", "orange"]
list2 = ["banana", "orange", "grape", "kiwi"]

common = set(list1) & set(list2)
print(f"Common: {common}")  # {'banana', 'orange'}

# Find elements unique to each list
only_in_list1 = set(list1) - set(list2)
only_in_list2 = set(list2) - set(list1)
print(f"Only in list1: {only_in_list1}")  # {'apple', 'cherry'}
print(f"Only in list2: {only_in_list2}")  # {'grape', 'kiwi'}
```

### Example 3: Tracking Students Across Classes

```python
# Track which students are in each class
class_a = {"Alice", "Bob", "Charlie", "David"}
class_b = {"Charlie", "David", "Eve", "Frank"}

# Students in at least one class
all_students = class_a | class_b
print(f"All students: {all_students}")

# Students in both classes
both_classes = class_a & class_b
print(f"In both classes: {both_classes}")

# Students in class_a but not in class_b
only_class_a = class_a - class_b
print(f"Only in class A: {only_class_a}")

# Students in exactly one class
only_one = class_a ^ class_b
print(f"Exactly one class: {only_one}")
```

### Example 4: Analyzing Text for Unique and Common Words

```python
# Compare words appearing in two texts
text1 = "the quick brown fox jumps over the lazy dog"
text2 = "the lazy dog sleeps by the quick brown fox"

words1 = set(text1.split())
words2 = set(text2.split())

common_words = words1 & words2
unique_to_text1 = words1 - words2
unique_to_text2 = words2 - words1

print(f"Common words: {common_words}")
print(f"Unique to text 1: {unique_to_text1}")
print(f"Unique to text 2: {unique_to_text2}")
```

### Example 5: Tracking Unique Visitors

```python
# Track unique daily visitors to a website
daily_visitors = [
    ["user1", "user2", "user3"],
    ["user2", "user4", "user5"],
    ["user1", "user3", "user6"],
    ["user2", "user5", "user7"]
]

# Combine all visitors
all_visitors = set()
for visitors in daily_visitors:
    all_visitors.update(visitors)

print(f"Total unique visitors: {len(all_visitors)}")
print(f"All visitors: {all_visitors}")

# Find users who visited every day
visitors_by_day = [set(day) for day in daily_visitors]
daily_visitors_set = set.intersection(*visitors_by_day)
print(f"Visited every day: {daily_visitors_set}")
```

## When to Use Sets

Sets are the right choice when we need to:

- Store unique values with automatic duplicate removal
- Perform mathematical set operations (union, intersection, difference)
- Test membership quickly for large collections
- Remove duplicates from a collection efficiently
- Compare two collections to find similarities or differences

We avoid sets when we need to:

- Maintain a specific order of elements
- Store duplicate values
- Access elements by index
- Store mutable elements inside the collection

Sets provide powerful tools for handling unique collections and performing set operations efficiently in Python.
