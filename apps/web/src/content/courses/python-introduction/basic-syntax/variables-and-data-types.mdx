# Variables and Data Types

This chapter explores how to store information in programs using variables, and covers Python's fundamental data types.

## What Are Variables?

You can think of variables as labeled containers that hold data. They are like labeled boxes where values are stored to use later in a program.

A variable has two parts: a name and a value. The name identifies the variable, and the value stores the actual data. When you write `name = "Alice"`, you create a variable named `name` that holds the value `"Alice"`.

### Understanding Data Types

Every value in Python has a specific type that determines what kind of data it represents. A data type defines the possible values and the operations that can be performed on that data.

To create a variable, you assign a value to a name using the equals sign (`=`). Python automatically determines the data type based on the value you assign.

```python
# Creating variables
name = "Alice"          # text (str)
age = 25                # number (int)
height = 1.75            # decimal (float)
is_student = True       # true/false (bool)
```

In this example:
- `name` holds a text value. Python stores this as a **string** (str)
- `age` holds a whole number. Python stores this as an **integer** (int)
- `height` holds a decimal number. Python stores this as a **float** (float)
- `is_student` holds a true/false value. Python stores this as a **boolean** (bool)

Python does not require you to declare the type of a variable upfront. The type is inferred from the value you assign.

## Naming Variables

Python has rules for naming variables:

- Variable names must start with a letter or underscore
- The rest of the name can contain letters, numbers, and underscores
- Names are case-sensitive (`age` and `Age` are different)

You use underscores to separate words in variable names for readability.

```python
# Valid variable names
first_name = "John"
lastName = "Doe"
age2 = 30
_is_private = True

# Invalid variable names
# 2age = 20        # Cannot start with a number
# first-name = "John"  # Cannot use hyphens
```

The first example shows valid variable names. The second block shows common mistakes to avoid.

## Python's Core Data Types

Python provides several data types that you will use frequently.

### Strings (str)

The first data type that we will cover are strings. Strings represent text and you can create them using single quotes or double quotes.

```python
# String examples
greeting = "Hello"
name = 'Alice'

# Multi-line strings
message = """
This is a
multi-line
string
"""

# String operations
first = "Hello"
second = "World"
combined = first + " " + second  # "Hello World"

# String repetition
echo = "Ha" * 3  # "HaHaHa"
```

To combine strings together, you use the `+` operator. This is called **concatenation** - joining two or more strings end to end.

The asterisk (`*`) performs repetition when used with a string and an integer. It repeats the string the number of times specified by the integer.

To learn more about operators, check out the [Operators](/courses/python-introduction/basic-syntax/operators) section.

### Integers (int)

The next data type to consider are integers. Integers are whole numbers without a decimal point.

```python
# Integer examples
count = 42
negative = -10
big_number = 1_000_000  # Underscores make large numbers readable

# Operations
a = 10
b = 3
sum_val = a + b      # 13
difference = a - b   # 7
product = a * b      # 30
```

You can perform arithmetic operations directly on integers. Note that the division operator (`/`) returns a float even when dividing evenly.

### Floating-Point Numbers (float)

Another important data type are floats. Floats are numbers with a decimal point.

```python
# Float examples
price = 19.99
temperature = -3.5
scientific = 2.5e-3  # Scientific notation: 0.0025

# Precision note
result = 0.1 + 0.2   # 0.30000000000000004 (floating-point precision)
```

Floats can represent very large or very small numbers using scientific notation with the `e` notation.

### Booleans (bool)

Booleans represent truth values: `True` or `False`. This data type is fundamental to programming because every decision in a program depends on a boolean value.

You will use booleans in several situations:

- **Conditional logic** - Making decisions in your code (if statements, loops)
- **Comparisons** - Comparing values to get a truth result
- **Boolean algebra** - Combining multiple conditions with `and`, `or`, and `not`

```python
# Boolean examples
is_active = True
is_empty = False

# Boolean from comparisons
age = 25
is_older = age > 18  # True if age is greater than 18
```

You will often create booleans through comparison operations. Comparisons evaluate to `True` or `False`.

To learn more about boolean algebra and logical operators, check out the [Control Flow](/courses/python-introduction/control-flow/if-statements) section.

## Checking Types with type()

To find out what type a variable is, you can use the `type()` function.

```python
name = "Alice"
age = 25
height = 1.75
is_student = True

print(type(name))       # <class 'str'>
print(type(age))        # <class 'int'>
print(type(height))     # <class 'float'>
print(type(is_student)) # <class 'bool'>
```

The `type()` function returns the data type of a value. This helps verify what type Python has inferred.

## Type Conversion

Values in Python can be converted from one type to another. This is called **type conversion** or **type casting**. Python provides built-in functions for converting between the common types.

### Converting to Integers

To convert a value to an integer, you use the `int()` function.

```python
# String to integer
num_str = "42"
num = int(num_str)      # 42
print(num)              # 42
```

When converting strings with decimal points to integers, Python truncates the decimal portion rather than rounding.

```python
# Float to integer (truncates, not rounds)
pi = 3.14159
pi_int = int(pi)        # 3
```

You can also convert booleans to integers. `True` becomes `1` and `False` becomes `0`.

```python
print(int(True))   # 1
print(int(False))  # 0
```

### Converting to Strings

To convert a value to a string, you use the `str()` function. This is one of the most common conversions, especially when you need to combine numbers with text.

```python
# Integer to string
age = 25
age_str = str(age)      # "25"
print(age_str)           # "25"
```

Once a value is a string, you can concatenate it with other strings.

```python
# Combining strings and numbers
name = "Alice"
age = 25
message = "My name is " + name + " and I am " + str(age) + " years old"
print(message)  # My name is Alice and I am 25 years old
```

### Converting to Floats

To convert a value to a floating-point number, you use the `float()` function.

```python
# String to float
price = float("19.99")  # 19.99
print(price)            # 19.99

# Integer to float
count = 10
count_float = float(count)  # 10.0
print(count_float)           # 10.0
```

### Converting to Booleans

To convert a value to a boolean, you use the `bool()` function. In Python, almost any value can be converted to a boolean.

```python
# Non-zero numbers become True
print(bool(1))       # True
print(bool(-5))      # True

# Zero becomes False
print(bool(0))       # False

# Non-empty strings become True
print(bool("hello")) # True

# Empty strings become False
print(bool(""))      # False

# None becomes False
print(bool(None))    # False
```

This conversion is particularly useful in conditional statements. When you use a value in a boolean context, Python automatically evaluates its truthiness.

```python
username = ""

if username:
    print(f"Welcome, {username}")
else:
    print("Please enter a username")

# Output: Please enter a username
```

### Common Conversion Patterns

Here are some practical conversion patterns you will use frequently:

**User input to numbers**
When you receive input from a user, it always comes as a string. You need to convert it to a number before doing math.

```python
# User enters "10" but it comes as a string
age_str = input("Enter your age: ")  # User types "10"
age = int(age_str)                   # Convert to integer

# Now you can do math
years_until_100 = 100 - age
print(f"You will be 100 in {years_until_100} years")
```

**Combining numbers with strings in print statements**
Use `str()` or f-strings to combine different types in output.

```python
score = 85
print("Your score: " + str(score))        # String concatenation
print(f"Your score: {score}")             # f-string (cleaner)
```

**Validating numeric input**
Always validate before converting to avoid errors.

```python
user_input = "not a number"

if user_input.isdigit():
    number = int(user_input)
    print(f"Double your number is {number * 2}")
else:
    print("Please enter a valid number")
```

## None Type

Sometimes, a variable has no value at all. Not zero, not an empty string, but literally the absence of a value. Python provides a special type called `None` for this purpose.

When you assign `None` to a variable, you are saying "this variable exists, but it does not contain any meaningful value yet". This is different from an empty string `""` or zero `0`, which are still actual values.

```python
# None represents the absence of a value
result = None
print(result)  # None
```

### Why Use None?

You will encounter `None` in several common situations:

**1. Initialize variables before they receive a real value**
When you create a variable that will be assigned later, you can set it to `None` as a placeholder.

```python
# Waiting for user input
username = None

# Later in your program...
username = "alice"
```

**2. Functions that do not return a value**
Some functions perform an action but do not return any result. In Python, these functions return `None` by default.

```python
def greet(name):
    print(f"Hello, {name}!")
    # This function does not return anything

message = greet("Alice")
print(message)  # None
```

**3. Missing dictionary values**
When you access a dictionary key that does not exist, you can use `None` as a default value.

```python
user = {"name": "Alice", "age": 25}

# Get a key that might not exist
email = user.get("email")  # Returns None if key is missing
print(email)  # None

# You can also specify a custom default
email = user.get("email", "not provided")
print(email)  # not provided
```

### Checking for None

To check if a variable is `None`, you use the `is` operator rather than the equality operator `==`.

```python
result = None

# Correct way to check for None
if result is None:
    print("No result yet")

# This also works but is not the Python convention
if result == None:
    print("No result yet")
```

The reason we use `is None` instead of `== None` is that `None` is a singleton in Python. There is only one `None` object in memory, so `is` checks identity (are they the same object?), while `==` checks equality (do they have the same value?). Since there is only one `None`, both work, but `is None` is the Pythonic convention.

## Working with Variables

### Multiple Assignment

Python allows assigning multiple variables in one line.

```python
# Multiple assignment
x, y, z = 1, 2, 3

# Same value to multiple variables
a = b = c = 10
```

Multiple assignment lets you assign different values to different variables in a single line.

### Swapping Variables

Swapping values between variables is intuitive in Python. Python supports tuple unpacking which makes swapping variables easy without needing a temporary variable.

```python
# Swapping values
a, b = 5, 10
a, b = b, a  # Now a = 10 and b = 5
```
