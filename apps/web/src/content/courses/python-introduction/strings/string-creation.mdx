# String Creation and Manipulation

Strings represent text in Python. We work with sequences of characters to store and manipulate textual data.

## Creating Strings

We create strings using single quotes, double quotes, or triple quotes for multi-line strings:

```python
greeting = "Hello, World!"
name = 'Alice'
message = """This is a
multi-line
string"""
```

Single and double quotes function identically. We choose whichever is more convenient when a string contains quotes:

```python
sentence = "It's a beautiful day"
quote = 'She said, "Hello!"'
```

## Escape Sequences

We use escape sequences to include special characters in strings. Escape sequences begin with a backslash:

```python
print("Line 1\nLine 2")
print("Column 1\tColumn 2")
path = "C:\\Users\\John"
text = "He said \"Hello\""
```

Common escape sequences include:

- `\\` — Backslash
- `\'` — Single quote
- `\"` — Double quote
- `\n` — Newline
- `\t` — Tab

## String Concatenation

We combine strings using the `+` operator:

```python
first_name = "John"
last_name = "Doe"
full_name = first_name + " " + last_name
print(full_name)
# Output: John Doe
```

We repeat strings using the `*` operator:

```python
separator = "-" * 10
print(separator)
# Output: ----------
```

## String Indexing

Each character in a string has an index starting from zero. We access individual characters with square brackets:

```python
text = "Python"
print(text[0])
# Output: P
print(text[1])
# Output: y
print(text[2])
# Output: t
```

Negative indexing counts from the end of the string:

```python
text = "Python"
print(text[-1])
# Output: n
print(text[-2])
# Output: o
print(text[-3])
# Output: h
```

## String Slicing

We extract portions of a string using slicing with syntax `string[start:end]`. The end index is not included:

```python
text = "Python Programming"
print(text[0:5])
# Output: Pytho
print(text[7:])
# Output: Programming
print(text[:6])
# Output: Python
print(text[-11:-1])
# Output: Programmin
```

We specify a step value with `string[start:end:step]`:

```python
text = "Python"
print(text[::2])
# Output: Pto
print(text[::-1])
# Output: nohtyP
```

## String Immutability

Strings in Python are immutable. We cannot change a string in place after creation, but we create a new string based on the old one:

```python
text = "Hello"
new_text = "J" + text[1:]
print(new_text)
# Output: Jello
```

## Built-in String Functions

Python provides these built-in functions for string operations:

```python
text = "hello world"
print(len(text))
# Output: 11
print(text.upper())
# Output: HELLO WORLD
print(text.lower())
# Output: hello world
print(text.count("o"))
# Output: 2
```
