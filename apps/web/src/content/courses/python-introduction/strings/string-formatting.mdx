# String Formatting

String formatting lets us insert values into strings. Python provides several approaches ranging from simple concatenation to modern f-strings.

## String Concatenation

We use the `+` operator for the simplest approach:

```python
name = "Alice"
age = 25
greeting = "Hello, " + name + "! You are " + str(age) + " years old."
print(greeting)
# Output: Hello, Alice! You are 25 years old.
```

We must convert non-string values to strings using `str()`.

## The format() Method

The `format()` method offers more flexibility and readability than concatenation.

### Positional Arguments

We reference arguments by position using `{}`:

```python
template = "Hello, {}! You are {} years old."
print(template.format("Alice", 25))
# Output: Hello, Alice! You are 25 years old.
```

### Named Arguments

We reference arguments by name:

```python
template = "Hello, {name}! You are {age} years old."
print(template.format(name="Bob", age=30))
# Output: Hello, Bob! You are 30 years old.
```

### Mixed Arguments

We can mix positional and named arguments:

```python
template = "{0} is {1} years old. {0} likes {activity}."
print(template.format("Alice", 25, activity="coding"))
# Output: Alice is 25 years old. Alice likes coding.
```

### Formatting Numbers

We control decimal places with format specs:

```python
pi = 3.14159
print("Pi is approximately {:.2f}".format(pi))
# Output: Pi is approximately 3.14
```

We add thousands separators:

```python
population = 7800000000
print("World population: {:,}".format(population))
# Output: World population: 7,800,000,000
```

We format percentages:

```python
ratio = 0.75
print("Progress: {:.0%}".format(ratio))
# Output: Progress: 75%
```

We pad with zeros:

```python
number = 42
print("Number: {:05}".format(number))
# Output: Number: 00042
```

### Alignment

We control text alignment within a specified width. Right-align uses `>`, left-align uses `<`, and center uses `^`:

```python
name = "Alice"
print("|{:>10}|".format(name))
# Output: |     Alice|
print("|{:<10}|".format(name))
# Output: |Alice     |
print("|{:^10}|".format(name))
# Output: |   Alice   |
```

We use a fill character:

```python
print("|{:*^10}|".format(name))
# Output: |***Alice***|
```

## F-Strings (Formatted String Literals)

F-strings, available since Python 3.6, provide the most readable way to format strings. We prefix the string with `f` and include expressions in curly braces:

```python
name = "Alice"
age = 25
print(f"Hello, {name}! You are {age} years old.")
# Output: Hello, Alice! You are 25 years old.
```

We include expressions directly in f-strings:

```python
a = 5
b = 3
print(f"{a} + {b} = {a + b}")
# Output: 5 + 3 = 8
```

### Calling Functions and Methods

We call functions and methods directly within f-strings:

```python
name = "alice"
print(f"Hello, {name.upper()}!")
# Output: Hello, ALICE!

text = "Python"
print(f"The word '{text}' has {len(text)} letters.")
# Output: The word 'Python' has 6 letters.
```

### F-String Formatting Options

We add formatting specs inside f-strings:

```python
pi = 3.14159
print(f"Pi is approximately {pi:.2f}")
# Output: Pi is approximately 3.14
```

We use alignment:

```python
name = "Alice"
print(f"|{name:>10}|")
# Output: |     Alice|
```

We format percentages:

```python
progress = 0.75
print(f"Progress: {progress:.0%}")
# Output: Progress: 75%
```

### Debugging with F-Strings

Python 3.8+ supports self-documenting expressions:

```python
x = 10
y = 5
print(f"{x = }")
# Output: x = 10
print(f"{x + y = }")
# Output: x + y = 15
```

## String Formatting Comparison

All methods produce equivalent results:

```python
name = "Alice"
age = 25

result1 = "Name: " + name + ", Age: " + str(age)
result2 = "Name: {}, Age: {}".format(name, age)
result3 = "Name: {n}, Age: {a}".format(n=name, a=age)
result4 = f"Name: {name}, Age: {age}"

print(result4)
# Output: Name: Alice, Age: 25
```

## Legacy String Formatting

Python also supports the `%` style formatting:

```python
name = "Alice"
age = 25
result = "Name: %s, Age: %d" % (name, age)
print(result)
# Output: Name: Alice, Age: 25
```

This style remains in older codebases but f-strings offer better readability.

## Common Use Cases

### Printing Tables

```python
data = [
    ["Alice", 25, "NYC"],
    ["Bob", 30, "LA"],
    ["Charlie", 35, "Chicago"]
]

print(f"{'Name':<10} {'Age':<5} {'City':<10}")
print("-" * 25)
for name, age, city in data:
    print(f"{name:<10} {age:<5} {city:<10}")
```

Output:
```
Name       Age   City
-------------------------
Alice      25    NYC
Bob        30    LA
Charlie    35    Chicago
```

### Formatted Output

We format currency:

```python
price = 19.99
print(f"Price: ${price:.2f}")
# Output: Price: $19.99
```

We use scientific notation:

```python
number = 12345678
print(f"Number: {number:.2e}")
# Output: Number: 1.23e+07
```

## Best Practices

1. **Use f-strings for new code** — They provide the best readability and performance
2. **Be consistent** — Choose one formatting style and use it throughout a project
3. **Use meaningful variable names** — They make debugging easier with self-documenting expressions
4. **Remember type handling** — F-strings handle types automatically

```python
user = "Alice"
score = 95
print(f"User {user} scored {score} points.")
```

## Quick Reference

| Method | Syntax | Example |
|--------|--------|---------|
| Concatenation | `str1 + str2` | `"A" + "B"` |
| format() | `"{x}".format(x=value)` | `"{n}".format(n="A")` |
| f-string | `f"{value}"` | `f"{n}"` |
| % formatting | `"%s" % value` | `"%s" % "A"` |

We prefer f-strings for most situations due to their readability and performance.
