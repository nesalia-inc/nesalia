# String Methods

Python string methods enable us to search, modify, and analyze text efficiently.

## Case Methods

The `upper()` method converts all characters to uppercase:

```python
text = "Hello World"
print(text.upper())
# Output: HELLO WORLD
```

The `lower()` method converts all characters to lowercase:

```python
print(text.lower())
# Output: hello world
```

The `title()` method converts the first letter of each word to uppercase:

```python
print(text.title())
# Output: Hello World
```

The `istitle()` method returns `True` if the string follows title case rules:

```python
print(text.istitle())
# Output: True
```

The `swapcase()` method swaps uppercase and lowercase:

```python
print(text.swapcase())
# Output: hELLO wORLD
```

## Searching and Finding

The `find()` method returns the position of a substring, or `-1` if not found:

```python
text = "The quick brown fox jumps over the lazy dog"
print(text.find("fox"))
# Output: 16
print(text.find("cat"))
# Output: -1
```

We can start searching from a specific position:

```python
print(text.find("the", 10))
# Output: 32
```

The `count()` method counts occurrences of a substring:

```python
print(text.count("the"))
# Output: 2
```

The `startswith()` method checks if a string begins with a specified substring:

```python
print(text.startswith("The"))
# Output: True
```

The `endswith()` method checks if a string ends with a specified substring:

```python
print(text.endswith("dog"))
# Output: True
```

## Checking String Content

The `isalpha()` method returns `True` if all characters are alphabetic:

```python
print("Hello123".isalpha())
# Output: False
print("hello".isalpha())
# Output: True
```

The `isdigit()` method returns `True` if all characters are digits:

```python
print("12345".isdigit())
# Output: True
print("hello".isdigit())
# Output: False
```

The `isalnum()` method returns `True` if all characters are alphanumeric:

```python
print("Hello123".isalnum())
# Output: True
```

The `isspace()` method returns `True` if all characters are whitespace:

```python
print("   ".isspace())
# Output: True
```

The `isupper()` method returns `True` if all characters are uppercase:

```python
print("HELLO".isupper())
# Output: True
print("Hello".isupper())
# Output: False
```

The `islower()` method returns `True` if all characters are lowercase:

```python
print("hello".islower())
# Output: True
```

## Modifying Strings

The `strip()` method removes leading and trailing whitespace:

```python
text = "  Hello World  "
print(text.strip())
# Output: Hello World
```

The `lstrip()` method removes only leading whitespace:

```python
print(text.lstrip())
# Output: Hello World
```

The `rstrip()` method removes only trailing whitespace:

```python
print(text.rstrip())
# Output:   Hello World
```

The `strip()` method removes specific characters from both ends:

```python
text = "###Hello###"
print(text.strip("#"))
# Output: Hello
```

The `replace()` method replaces all occurrences of a substring:

```python
text = "I like cats"
print(text.replace("cats", "dogs"))
# Output: I like dogs
print("one two one two".replace("one", "three"))
# Output: three two three two
```

The `split()` method splits a string into a list:

```python
text = "apple,banana,cherry"
print(text.split(","))
# Output: ['apple', 'banana', 'cherry']
print("Hello World".split())
# Output: ['Hello', 'World']
print("a,b,c,d".split(",", 2))
# Output: ['a', 'b', 'c,d']
```

The `join()` method joins a list into a string:

```python
words = ["apple", "banana", "cherry"]
print(",".join(words))
# Output: apple,banana,cherry
print(" ".join(words))
# Output: apple banana cherry
```

## String Formatting

The `center()` method centers text within a specified width:

```python
text = "Hello"
print(text.center(20))
# Output:        Hello
print(text.center(20, "-"))
# Output: -------Hello--------
```

The `ljust()` method left-aligns text:

```python
print(text.ljust(20))
# Output: Hello
print(text.ljust(20, "."))
# Output: Hello...............
```

The `rjust()` method right-aligns text:

```python
print(text.rjust(20))
# Output:               Hello
print(text.rjust(20, "."))
# Output: ...............Hello
```

The `zfill()` method pads a numeric string with zeros:

```python
number = "42"
print(number.zfill(6))
# Output: 000042
```

## Practical Examples

We combine methods to clean and process user input:

```python
user_input = "  ALICE smith  "
cleaned = user_input.strip().title()
print(cleaned)
# Output: Alice Smith
```

We validate an email address:

```python
email = "user@example.com"
is_valid = "@" in email and email.endswith(".com")
print(is_valid)
# Output: True
```

We extract the domain from an email:

```python
email = "user@example.com"
username, domain = email.split("@")
print(domain)
# Output: example.com
```

We count words in a sentence:

```python
sentence = "The quick brown fox jumps over the lazy dog"
word_count = len(sentence.split())
print(word_count)
# Output: 9
```

## Key Insight

String methods do not modify the original string. They return a new string. Since strings in Python are immutable, all methods that appear to modify strings actually return a copy:

```python
text = "Hello"
new_text = text.upper()
print(text)
# Output: Hello (unchanged)
print(new_text)
# Output: HELLO (new value)
```
