# String Methods

Python provides many useful methods for working with strings. These methods allow you to search, modify, and analyze text without writing complex code from scratch.

## Case Methods

These methods change the case of the string:

```python
text = "Hello World"

# Convert to uppercase
print(text.upper())       # Output: HELLO WORLD

# Convert to lowercase
print(text.lower())       # Output: hello world

# Convert to title case (first letter of each word)
print(text.title())       # Output: Hello World

# Convert to title case (first letter of each word, ignoring exceptions)
print(text.istitle())     # Output: True

# Swap uppercase and lowercase
print(text.swapcase())    # Output: hELLO wORLD
```

## Searching and Finding

Find where specific text appears in a string:

```python
text = "The quick brown fox jumps over the lazy dog"

# Find the position of a substring (returns -1 if not found)
print(text.find("fox"))        # Output: 16
print(text.find("cat"))         # Output: -1

# Find from a specific position
print(text.find("the", 10))     # Output: 32

# Count occurrences
print(text.count("the"))        # Output: 2

# Check if string starts/ends with specific text
print(text.startswith("The"))  # Output: True
print(text.endswith("dog"))     # Output: True
```

## Checking String Content

Python provides methods to check what kind of content a string contains:

```python
text1 = "Hello123"
text2 = "hello"
text3 = "12345"
text4 = "   "
text5 = "Hello World"

# Check if all characters are alphabetic
print(text1.isalpha())   # Output: False (contains numbers)
print(text2.isalpha())   # Output: True

# Check if all characters are digits
print(text3.isdigit())   # Output: True
print(text2.isdigit())   # Output: False

# Check if all characters are alphanumeric
print(text1.isalnum())    # Output: True

# Check if all characters are whitespace
print(text4.isspace())    # Output: True

# Check if string is in title case
print(text5.istitle())    # Output: True

# Check if string is uppercase/lowercase
print(text5.isupper())    # Output: False
print(text2.islower())    # Output: True
```

## Modifying Strings

Transform and modify strings in various ways:

```python
text = "  Hello World  "

# Remove leading and trailing whitespace
print(text.strip())      # Output: Hello World

# Remove only leading or trailing whitespace
print(text.lstrip())     # Output: Hello World
print(text.rstrip())     # Output:   Hello World

# Remove specific characters from ends
text2 = "###Hello###"
print(text2.strip("#"))  # Output: Hello
```

Replace parts of a string:

```python
text = "I like cats"

# Replace a substring
print(text.replace("cats", "dogs"))  # Output: I like dogs

# Replace all occurrences
text2 = "one two one two"
print(text2.replace("one", "three"))  # Output: three two three two
```

Split a string into a list:

```python
text = "apple,banana,cherry"

# Split by delimiter
print(text.split(","))   # Output: ['apple', 'banana', 'cherry']

# Split by whitespace
text2 = "Hello World"
print(text2.split())     # Output: ['Hello', 'World']

# Split into at most N+1 parts
text3 = "a,b,c,d"
print(text3.split(",", 2))  # Output: ['a', 'b', 'c,d']
```

Join a list into a string:

```python
words = ["apple", "banana", "cherry"]

# Join with a delimiter
print(",".join(words))   # Output: apple,banana,cherry
print(" ".join(words))   # Output: apple banana cherry
```

## String Formatting

Align and format strings:

```python
text = "Hello"

# Center the text
print(text.center(20))        # Output:        Hello
print(text.center(20, "-"))    # Output: -------Hello--------

# Left-align
print(text.ljust(20))         # Output: Hello
print(text.ljust(20, "."))    # Output: Hello...............

# Right-align
print(text.rjust(20))         # Output:               Hello
print(text.rjust(20, "."))    # Output: ...............Hello

# Zero-fill (for numeric strings)
number = "42"
print(number.zfill(6))        # Output: 000042
```

## Practical Examples

Combining methods together:

```python
# Clean and process user input
user_input = "  ALICE smith  "
cleaned = user_input.strip().title()
print(cleaned)  # Output: Alice Smith

# Validate an email address
email = "user@example.com"
is_valid = "@" in email and email.endswith(".com")
print(is_valid)  # Output: True

# Extract domain from email
email = "user@example.com"
username, domain = email.split("@")
print(domain)  # Output: example.com

# Count words in a sentence
sentence = "The quick brown fox jumps over the lazy dog"
word_count = len(sentence.split())
print(word_count)  # Output: 9
```

## Remember

String methods do not modify the original string. They return a new string. Strings in Python are immutable, so all methods that modify strings return a copy:

```python
text = "Hello"
new_text = text.upper()

print(text)      # Output: Hello (unchanged!)
print(new_text)  # Output: HELLO (new value)
```
