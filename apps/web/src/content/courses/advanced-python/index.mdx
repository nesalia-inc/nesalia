# Advanced Python

This course covers advanced Python concepts and techniques that build on the fundamentals. You will learn about decorators, generators, metaclasses, type annotations, concurrency patterns, design patterns, and production best practices.

## What You Will Learn

By completing this course, you will be able to:

- Write decorators and understand the functools module
- Create and use generators for memory-efficient processing
- Build context managers for resource management
- Design custom collections and implement iterables
- Work with multiple inheritance and metaclasses
- Use advanced type annotations for better code documentation
- Implement concurrent and parallel execution patterns
- Write comprehensive tests and debug Python applications
- Apply design patterns to solve real-world problems
- Serialize and deserialize data with JSON, YAML, and Pickle

## Prerequisites

Before starting this course, you should have completed the Introduction to Python course or have equivalent knowledge of Python fundamentals including variables, data types, functions, and basic object-oriented concepts.

## Chapters

1. [Advanced Functions](/courses/advanced-python/advanced-functions/decorators) - Decorators, functools, generators, context managers, walrus operator
2. [Advanced Data Structures](/courses/advanced-python/advanced-data-structures/collections-module) - collections module, ChainMap, namedtuple, comprehensions, sorting
3. [Object-Oriented Programming](/courses/advanced-python/object-oriented-programming/multiple-inheritance-mro) - MRO, super(), abstract classes, enums, properties, dunder methods, dataclasses, descriptors, pattern matching
4. [Metaprogramming](/courses/advanced-python/metaprogramming/init-new-call) - __new__, __init__, __call__, __slots__, metaclasses, class creation patterns
5. [Advanced Type Annotations](/courses/advanced-python/advanced-type-annotations/generic-types) - Generics, Union, Optional, TypedDict, Protocols, TypeVar, @overload, @override, @final
6. [Collections and Iterators](/courses/advanced-python/collections-and-iterators/collections-abc) - collections.abc, custom iterables, ABCs for interfaces
7. [Concurrency and Parallelism](/courses/advanced-python/concurrency-and-parallelism/threading-gil) - Threading, multiprocessing, asyncio, concurrent.futures
8. [Testing and Debugging](/courses/advanced-python/testing-and-debugging/unit-testing) - Unit testing, fixtures, mocking, coverage, pdb
9. [Design Patterns](/courses/advanced-python/design-patterns/singleton-factory) - Singleton, Factory, Observer, Strategy, State, Builder, Prototype
10. [Working with External Data](/courses/advanced-python/working-with-external-data/json-pickle) - JSON, Pickle, YAML, regular expressions, CSV, Pandas
11. [Production Python](/courses/advanced-python/production-python/logging-configuration) - Logging, environment variables, dependency management, mypy, Black, Ruff

## Course Structure

Each chapter contains:

- **Conceptual explanations** - What each concept is, why it exists, and when to use it
- **Code examples** - Real code demonstrating every feature with explanations
- **Practical applications** - Real-world patterns you can apply immediately
- **Cross-references** - Links to related sections within the course

## Getting Started

Start with Chapter 1 "Advanced Functions" to begin exploring Python's advanced capabilities.
