## Why Testing Matters

Automated tests are the safety net that enables confident refactoring and deployment. This guide covers pytest and modern testing patterns.

## pytest Setup

```bash
pip install pytest pytest-asyncio pytest-cov pytest-mock
```

## Basic Test Structure

```python
# tests/test_users.py
import pytest
from users.models import User
from users.services import UserService

class TestUserService:
    @pytest.fixture
    def user_service(self):
        return UserService()

    @pytest.fixture
    def sample_user_data(self):
        return {
            "username": "testuser",
            "email": "test@example.com",
            "password": "secure123"
        }

    def test_create_user(self, user_service, sample_user_data):
        user = user_service.create_user(**sample_user_data)
        assert user.username == "testuser"
        assert user.email == "test@example.com"

    def test_create_user_duplicate_email(self, user_service, sample_user_data):
        user_service.create_user(**sample_user_data)
        with pytest.raises(ValueError, match="Email already exists"):
            user_service.create_user(**sample_user_data)
```

## Async Testing

```python
import pytest

@pytest.fixture
def event_loop():
    loop = asyncio.get_event_loop_policy().new_event_loop()
    yield loop
    loop.close()

@pytest.mark.asyncio
async def test_async_user_fetch():
    user = await UserService().get_user(1)
    assert user.id == 1
```

## Mocking External Services

```python
from unittest.mock import patch, AsyncMock

@pytest.fixture
def mock_redis():
    with patch("redis.asyncio.Redis") as mock:
        mock.get = AsyncMock(return_value=b"cached_data")
        yield mock

@pytest.mark.asyncio
async def test_cached_user(mock_redis):
    result = await get_user_cached(1)
    assert result == "cached_data"
    mock_redis.get.assert_called_once_with("user:1")
```

## Best Practices

1. **Test behavior, not implementation** - Test what, not how
2. **Arrange-Act-Assert** - Clear test structure
3. **One assertion per test** - Focused, readable tests
4. **Meaningful names** - `test_user_cannot_register_with_duplicate_email`
