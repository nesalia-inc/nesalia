## Real-Time Streaming with Slack

Building a Slack bot that streams AI responses requires handling real-time events, managing conversation context, and delivering incremental updates to users.

## Setting Up the Slack Bot

```bash
pip install slack_bolt slack-sdk aiohttp
```

## Async Event Handler

```python
import asyncio
from slack_bolt import App
from slack_bolt.adapter.socket_mode import SocketModeHandler
from langchain.agents import Agent

app = App(token=os.environ["SLACK_BOT_TOKEN"])

@app.event("app_mention")
async def handle_app_mention(event, say, client):
    thread_ts = event["ts"]
    channel = event["channel"]

    # Acknowledge immediately
    await client.reactions_add(
        channel=channel,
        timestamp=thread_ts,
        name="brain"
    )

    # Stream response
    async def on_chunk(chunk):
        await client.reactions_add(
            channel=channel,
            timestamp=thread_ts,
            name="loading"
        )

    result = await agent.stream(
        prompt=event["text"],
        stream_handler=on_chunk
    )

    await thread.delete()
    await thread.reply(result.content)
```

## Conversation Context

```python
from langchain.memory import ConversationBufferMemory

memory = ConversationBufferMemory(memory_key="chat_history")

@app.event("message")
async def handle_message(event, say):
    if event.get("thread_ts"):
        # Part of a thread - add to memory
        memory.save_context(
            {"input": event["text"]},
            {"output": ""}
        )
```

## Best Practices

1. **Respond within 3 seconds** - Slack requires quick acknowledgment
2. **Use threads** - Keep channel clean with threaded replies
3. **Stream for long responses** - Show incremental progress
4. **Handle rate limits** - Implement exponential backoff
